Case Study · Unreal Engine Infotainment

Hyundai Mobis Connect In-Vehicle Infotainment Prototype

Unreal Engine implementation and real-time 3D content production for a vehicle interior infotainment experience, delivered through VIVE Studios / Hyundai Mobis as an EXE + APK software package across four content modules.

Period 2025.07-2025.12
Client VIVE Studios / Hyundai Mobis
Role Unreal Engine implementation
Output EXE + APK software package

Overview

In-Cabin Content Context

The project treats the vehicle display as a real-time content stage, where assistant characters, contextual cards, ambient spaces, and vehicle controls need to read as one infotainment experience.

Implementation Frame

The work translated content modules into Unreal Engine scenes and screen states, balancing 3D assets, motion, UI overlays, and review-ready packaged builds.

Visual Evidence

Production Scope

Define In-Cabin Screen Composition

Organized the content around driver-facing infotainment states, contextual notifications, app access, and vehicle control surfaces.

Implement Real-Time 3D Scenes

Built screen-ready Unreal Engine scenes that combine character presentation, background space, lighting, and motion-friendly content layers.

Integrate HMI and Content States

Connected cards, icons, status indicators, and climate controls into coherent screen compositions for infotainment review.

Package Review Builds

Prepared EXE and APK software packages so the content could be reviewed as an executable prototype rather than as static screen stills.

Outcome

Packaged Infotainment Prototype

The deliverable demonstrated how real-time 3D content can sit inside a vehicle infotainment environment, from character-led assistance to contextual route and weather displays.

Practice Area

This case anchors the portfolio's real-time engine practice in automotive R&D, complementing AI UI/UX projects and digital twin production systems.
