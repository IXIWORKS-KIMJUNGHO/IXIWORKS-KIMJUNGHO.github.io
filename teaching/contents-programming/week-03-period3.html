완료 조건

자동 검사 통과 + 두 파일 제출 확인 = 즉시 귀가

선택 확장은 의무가 아닙니다. 필수 결과물을 완성했다면 추가 도형을 만들거나 다른 학생을 기다릴 필요가 없습니다.

귀가 조건: 제출 전에 여덟 가지 확인

  1. 노트북 파일명week03_학번_이름.ipynb 형식으로 변경했습니다.
  2. 제출 정보학번, 이름 또는 별명, 표현 의도, PNG 파일명을 작성했습니다.
  3. 팔레트 수정기준 팔레트에서 색상 역할을 최소 두 개 변경했습니다.
  4. 필수 도형사각형, 타원, 삼각형이 모두 이미지 안에서 보입니다.
  5. 좌표 수정세 도형 가운데 최소 두 도형의 좌표 묶음을 변경했습니다.
  6. PNG 저장week03_학번_이름.png 파일이 생성되었고 최종 이미지와 같습니다.
  7. 전체 재실행새 세션에서 모두 실행했을 때 오류 없이 완료 문구가 나타납니다.
  8. 두 파일 제출실행 결과가 포함된 `.ipynb`와 최종 `.png`를 제출했습니다.

자동 검사는 작품의 미적 취향을 채점하지 않는다

검사 셀은 RGB가 0~255인지, 도형이 캔버스 안에 있는지, 기준값을 실제로 수정했는지, PNG가 최신 상태로 저장되었는지만 확인합니다. 어떤 색이 더 아름다운지, 어느 구성이 더 좋은지는 하나의 정답으로 판정하지 않습니다.

기준 확인

제출 정보와 표현 의도 작성

STEP 1 코드 셀에서 = 오른쪽의 따옴표 안 내용만 자신의 정보로 바꿉니다. 변수 이름과 따옴표는 삭제하지 않습니다.

student_id = "20260000"
student_name = "김민지"

색상 역할을 최소 두 개 수정

STEP 2 팔레트 셀에는 다섯 색상 역할이 있습니다. 처음부터 다섯 줄을 모두 바꾸지 않습니다. 먼저 하나의 RGB 채널을 바꾸고 팔레트 미리보기를 확인한 뒤 다음 색으로 이동합니다.

# EDIT: 아래 RGB 숫자만 수정합니다.
background_color = (244, 239, 229)
primary_color = (235, 86, 75)
secondary_color = (48, 95, 180)
accent_color = (244, 190, 55)
outline_color = (28, 31, 38)
  • 각 RGB 값은 따옴표 없는 0~255 정수 세 개로 작성합니다.
  • 기준값과 다른 색상 역할이 최소 두 개 있어야 합니다.
  • 배경·주조·보조·강조·윤곽에는 서로 다른 색을 사용합니다.
  • 배경과 윤곽이 구분되고, 세 도형의 내부색이 최종 이미지에서 보여야 합니다.
색상 확인

셀 아래에 현재 변경한 색상 역할: 2개 이상이 출력되고, 팔레트 미리보기에서 다섯 역할의 관계를 확인했습니다.

RGB 검사에서 멈출 때

(R, G, B) 둥근괄호 안에 쉼표로 구분한 숫자가 정확히 세 개인지 확인합니다. 숫자에 따옴표를 붙이지 않았는지, 각 값이 0보다 작거나 255보다 크지 않은지도 확인합니다.

도형 좌표 묶음을 최소 두 개 수정

STEP 3 셀의 맨 위에 있는 세 좌표 묶음만 수정합니다. 아래쪽의 draw.rectangle(), draw.ellipse(), draw.polygon() 명령은 이미 준비되어 있으므로 다시 작성하지 않습니다.

# EDIT: 아래 세 좌표 묶음의 숫자만 수정합니다.
rectangle_box = (50, 60, 330, 240)
ellipse_box = (230, 100, 510, 360)
triangle_points = (
    (390, 55),
    (560, 220),
    (340, 220)
)
도형별 좌표 수정 방법
도형좌표 구조안전한 첫 수정
사각형(left, top, right, bottom)right를 20~40 변경해 가로 길이 비교
타원(left, top, right, bottom)top과 bottom 가운데 하나를 변경해 비율 비교
삼각형세 개의 (x, y)첫 점의 x 또는 y 하나를 20~40 이동

한 번에 숫자 하나만 바꾼다

도형 하나의 숫자 여러 개와 색상을 동시에 바꾸면 어떤 값이 결과를 만들었는지 알기 어렵습니다. 숫자 하나 수정 → STEP 3 다시 실행 → 결과 확인의 순서를 반복합니다.

좌표 확인

셀 아래에 현재 변경한 도형 좌표 묶음: 2개 이상이 출력되고, 사각형·타원·삼각형이 모두 화면 안에서 보입니다.

사각형이나 타원 좌표 오류가 나올 때

네 값을 (left, top, right, bottom) 순서로 읽습니다. left는 right보다 작고, top은 bottom보다 작아야 합니다. x는 0~599, y는 0~399 안에 둡니다.

삼각형이 너무 작거나 보이지 않을 때

세 점이 모두 캔버스 안에 있는지 확인하고, 세 점을 같은 가로선이나 세로선 위에 놓지 않습니다. 첫 점은 위쪽, 나머지 두 점은 서로 떨어진 아래쪽에 두면 기본적인 삼각형을 만들기 쉽습니다.

최종 이미지를 PNG로 저장

표현 의도와 이미지가 연결되는지 마지막으로 확인한 뒤 STEP 4 저장 셀을 실행합니다. 저장 코드는 수정하지 않습니다.

image.save(output_filename)

output_filename에는 STEP 1에서 작성한 week03_학번_이름.png가 저장되어 있습니다. 저장 셀은 PNG를 다시 열어 화면에 보여주므로, 마지막 미리보기와 저장된 파일이 같은지 눈으로 확인할 수 있습니다.

수정한 뒤에는 반드시 다시 저장한다

색상이나 좌표를 바꾼 뒤 STEP 3 이미지만 다시 만들고 저장 셀을 실행하지 않으면 PNG에는 이전 결과가 남을 수 있습니다. 최종 수정 후에는 STEP 3과 STEP 4를 차례로 실행합니다.

PNG가 최신 상태가 아니라는 오류가 나올 때

선택 확장: 완료 후 더 실험하고 싶은 경우만

아래 활동은 귀가 조건이 아니며 추가 점수도 없습니다. 필수 미션을 완료한 학생은 선택 확장을 하지 않고 제출 후 귀가해도 됩니다.

  • 같은 좌표에 두 번째 팔레트를 적용하고 다른 파일명으로 저장합니다.
  • 도형 코드의 실행 순서를 바꾸어 겹친 영역의 앞뒤 관계를 비교합니다.
  • 가로선의 위치나 두께를 수정하거나 선을 하나 더 추가합니다.
  • 사각형, 타원, 다각형 가운데 하나를 추가해 두 번째 강조점을 만듭니다.
