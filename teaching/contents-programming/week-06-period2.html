Parameter / Argument / Return

값으로 생성기 조절하기

매개변수에 값을 전달하고, return으로 결과를 받아 같은 규칙의 변주를 만듭니다.

함수의 입력을 바꾸고 생성된 이미지를 호출한 곳으로 돌려받기

형식
기본 50분 / 확장 60분 · + 10 MIN EXTENSION
핵심
매개변수, 인자, 지역 변수, return
연결
고정 함수 → 입력으로 조절하는 생성기

오늘의 학습 목표

  • 고정된 함수가 같은 결과만 만드는 이유를 설명하고 바꿀 요소를 입력 자리로 정할 수 있습니다.
  • 함수 정의에 적는 매개변수와 함수 호출에 전달하는 인자를 구분할 수 있습니다.
  • 위치 인자와 키워드 인자의 차이를 알고 여러 입력을 읽기 쉬운 방식으로 전달할 수 있습니다.
  • 함수 안에서 만든 지역 변수의 사용 범위를 설명할 수 있습니다.
  • return이 값을 출력하는 문장이 아니라 호출한 곳으로 결과를 전달하는 문장임을 설명할 수 있습니다.
  • 5주차 코드를 create_poster() 함수로 묶고 시드·도형 수·조건 기준·팔레트를 입력으로 전달할 수 있습니다.
  • 같은 입력은 같은 이미지를 재현하고 다른 입력은 같은 규칙의 변주를 만든다는 사실을 확인할 수 있습니다.

수업 운영: 기본 50분과 확장 60분

기본 50분에서는 매개변수와 인자의 구분, 위치·키워드 전달, 지역 변수, return, 완전한 이미지 생성 함수, 3교시 미션 계약까지 진행합니다. 각 개념은 숫자 함수에서 먼저 확인한 뒤 도형 함수와 포스터 함수로 확장합니다. 진도가 빠를 때만 50-60분 확장에서 하나의 함수에 세 입력 조합을 적용하고 어떤 값이 화면의 무엇을 바꾸었는지 기록합니다.

매개변수가 많은 함수를 읽는 순서

  1. 함수 이름으로 전체 작업을 확인합니다. create_poster는 포스터 한 장을 만드는 작업입니다.
  2. 정의 괄호의 매개변수를 왼쪽부터 읽습니다. 시드, 도형 수, 중간 기준, 큰 기준, 팔레트 순서입니다.
  3. 호출 괄호의 실제 값과 이름을 연결합니다. 키워드 인자를 사용하면 연결이 코드에 직접 보입니다.
  4. 함수 본문에서 각 입력이 쓰이는 위치를 한 곳씩 찾습니다. 모든 줄을 한꺼번에 이해하려 하지 않습니다.
  5. return 뒤의 값을 찾습니다. 그 값이 호출 결과로 함수 밖에 전달됩니다.

5-16분 · 매개변수는 입력 자리이고 인자는 실제 값이다

다음 함수는 위치, 크기, 색상을 함수 밖에서 받습니다. 정의 괄호의 x, y, size, color가 매개변수입니다.

27-38분 · return은 함수 안의 결과를 호출한 곳으로 전달한다

다음 함수는 x, y, size를 받아 Pillow 도형에 사용할 경계 상자를 계산합니다. return circle_box가 실행되면 계산된 튜플이 호출한 곳으로 전달되고 first_box에 저장됩니다.

def make_circle_box(x, y, size):
    circle_box = (x, y, x + size, y + size)
    return circle_box

first_box = make_circle_box(70, 90, 100)
print(first_box)

return, print, display, save는 목적이 다르다

함수 결과를 다루는 네 가지 동작
동작주요 목적호출한 곳에서 값 사용이번 생성기에서 위치
return image함수의 결과값 전달가능함수 본문의 마지막
print(value)문자나 숫자를 출력 영역에 표시표시만으로는 전달되지 않음검사와 설명에 사용
display(image)노트북에 이미지를 시각적으로 표시표시만으로는 전달되지 않음함수 호출 뒤 사용
image.save(filename)이미지를 파일로 저장파일이 생성됨결과 선택 뒤 사용

return은 화면에 자동으로 설명을 출력하는 명령이 아닙니다. 함수가 만든 값을 다른 변수에 저장하거나, 다른 함수에 전달하거나, 나중에 저장할 수 있도록 호출 위치로 돌려주는 명령입니다. 함수가 return 없이 끝나면 Python은 None을 돌려줍니다.

def make_title():
    title = "CONTROLLED CHANCE"
    print(title)

returned_value = make_title()
print("돌려받은 값:", returned_value)
OUTPUT

CONTROLLED CHANCE
돌려받은 값: None

첫 줄은 함수 안의 print()가 표시한 문자열이고, 둘째 줄의 None은 함수가 별도의 값을 반환하지 않았다는 뜻입니다. 이미지 생성 함수에서 return image를 빠뜨리면 호출 결과 변수에도 None이 저장되어 이후 display()나 save() 작업을 이어가기 어렵습니다.

함수 안에서 만든 변수는 기본적으로 함수 안에서 사용한다

make_circle_box() 안에서 만든 circle_box는 함수가 실행되는 동안 사용하는 지역 변수입니다. 함수 밖에서는 그 이름을 직접 사용하지 않고, return으로 받은 값을 새로운 변수에 저장합니다.

def make_circle_box(x, y, size):
    circle_box = (x, y, x + size, y + size)
    return circle_box

returned_box = make_circle_box(70, 90, 100)
print(returned_box)
Inside function circle_box

함수 본문에서 계산에 사용하는 지역 변수입니다. 함수의 작업 과정을 설명합니다.

Outside function returned_box

호출이 돌려준 값을 함수 밖에서 새로 저장한 변수입니다. 이후 도형 명령에 사용할 수 있습니다.

함수 밖에서 circle_box를 출력하면 왜 NameError가 나는가?

circle_box는 함수 호출 중 함수 안에서 만들어진 지역 변수이기 때문입니다. 함수 밖에서는 return으로 받은 returned_box를 사용합니다. 이번 수업에서는 global로 내부 변수를 억지로 밖에 노출하지 않습니다.

개별 판정 · 2분

화면 표시와 결과 반환 구분하기

“함수 안에서 이미지를 보여주었다”와 “함수 호출 결과로 이미지를 돌려받았다”가 같은 말인지 판단하고, 반환된 이미지로 할 수 있는 작업 두 가지를 적습니다.

표시와 반환 판정 답안

두 문장은 다릅니다. display(image)는 노트북 화면에 이미지를 보여주고, return image는 호출한 곳에 이미지 객체를 전달합니다. 반환된 이미지는 변수에 저장하고, 다시 표시하고, PNG로 저장하거나 다음 주의 자르기·합성 작업에 전달할 수 있습니다.

38-47분 · 5주차 코드를 create_poster 함수로 묶기

    canvas_width = 600
    canvas_height = 600
    min_size = 20
    max_size = 80
    margin = 40

    background_color = palette[0]
    primary_color = palette[1]
    secondary_color = palette[2]
    accent_color = palette[3]
    outline_color = palette[4]
    base_palette = [primary_color, secondary_color, accent_color]

    random.seed(seed_number)
    image = Image.new(
        "RGB",
        (canvas_width, canvas_height),
        background_color,
    )
    draw = ImageDraw.Draw(image)

    for shape_number in range(shape_count):
        size = random.randint(min_size, max_size)
        x = random.randint(
            margin,
            canvas_width - margin - size,
        )
        y = random.randint(
            margin,
            canvas_height - margin - size,
        )
        base_color = random.choice(base_palette)

        if size >= large_threshold:
            draw.rectangle(
                (x, y, x + size, y + size),
                fill=accent_color,
                outline=outline_color,
                width=3,
            )
        elif size >= medium_threshold:
            draw.ellipse(
                (x, y, x + size, y + size),
                fill=base_color,
            )
        else:
            draw.ellipse(
                (x, y, x + size, y + size),
                fill=background_color,
                outline=base_color,
                width=4,
            )

    return image

calm_palette = [
    (235, 241, 250),
    (48, 112, 166),
    (92, 150, 118),
    (230, 83, 72),
    (35, 42, 55),
]

poster_a = create_poster(
    seed_number=73,
    shape_count=56,
    medium_threshold=42,
    large_threshold=64,
    palette=calm_palette,
)

tobytes()는 자동 검사에서 두 이미지의 픽셀 데이터를 비교하기 위해 사용합니다. 학생이 이 메서드를 외울 필요는 없습니다. 기억할 핵심은 같은 함수에 같은 입력을 전달하면 같은 결과를 다시 확인할 수 있다는 점입니다.

시드를 함수 밖에서 한 번만 설정하면 왜 호출 결과가 달라질 수 있는가?
