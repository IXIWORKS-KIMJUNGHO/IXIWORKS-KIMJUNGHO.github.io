개별 예측

어느 줄이 원하는 결과가 아닌가

  1. "7" * 4의 결과는 28인가, 7777인가?
  2. average_rating = 4의 자료형은 int인가, float인가?
  3. wants_to_create = "True"의 자료형은 bool인가, str인가?
1. "7" * 4의 결과는?

7777입니다. 따옴표 안의 "7"은 글자이므로 곱하면 글자가 네 번 이어 붙습니다. 한 달 시간 28을 얻으려면 weekly_hours를 따옴표 없는 정수로 작성해야 합니다.

2. average_rating = 4의 자료형은?

int입니다. 실수로 저장하려면 4.0처럼 소수점을 함께 작성합니다. 자동 검사는 STEP 1의 평점이 float인지도 확인합니다.

3. wants_to_create = "True"의 자료형은?

str입니다. 따옴표가 있으면 글자입니다. 불리언으로 저장하려면 따옴표 없는 True 또는 False를 작성합니다.

STEP 5: 자동 검사 셀로 완료 증명

노트북 마지막의 FINAL CHECK 셀은 수정하지 않습니다. 필수 변수의 자료형과 입력 범위, 처음과 나중 값의 차이, 월간·연간 계산, 두 출력 결과, 새 런타임의 전체 실행 순서를 검사합니다. 아래 문법은 검사를 위한 도구이며 이번 주 학습 범위가 아닙니다.

자동 검사가 확인하는 항목

자동 검사에서 AssertionError가 나올 때

오류의 가장 마지막 한글 문장이 수정할 항목을 알려줍니다. 해당 변수의 따옴표, 소수점, True 또는 False 표기를 고친 뒤 STEP 1부터 다시 실행합니다. 검사 셀의 코드를 지워서 통과시키면 완료로 인정하지 않습니다.

SyntaxError가 나올 때

오류가 표시된 줄에서 여는 따옴표와 닫는 따옴표, 여는 괄호와 닫는 괄호가 모두 있는지 확인합니다. 한글 따옴표인 “ ”가 아니라 코드에 사용하는 곧은 따옴표 " "를 사용합니다.

TypeError 또는 자료형 검사 실패가 나올 때

weekly_hours는 따옴표 없는 정수, average_rating은 소수점이 있는 실수, wants_to_create는 따옴표 없는 True 또는 False인지 확인합니다. STEP 1의 type() 출력과 비교하면 원인을 빨리 찾을 수 있습니다.

  3. 교수자에게 그 화면을 보여 줍니다.
  4. 확인을 받으면 바로 퇴실합니다. 별도의 전체 마무리를 기다리지 않습니다.

자동 검사 PASS가 보이고 교수자가 화면을 확인했다면 오늘의 실습 목표를 달성했습니다. 파일 제출과 작업 속도, 남은 수업 시간은 성적에 넣지 않습니다.

선택 확장: 남아서 더 해보고 싶은 경우만

아래 활동은 퇴실 조건이 아니며 추가 점수도 없습니다. 필수 목표를 완료한 뒤 더 실험하고 싶은 학생만 진행합니다.

  • 출력 순서와 설명 문구를 바꾸어 자신만의 데이터 프로필로 정리합니다.
