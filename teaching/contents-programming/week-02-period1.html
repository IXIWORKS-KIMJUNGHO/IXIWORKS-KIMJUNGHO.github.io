Python의 역할

Python은 사람이 비교적 읽기 쉬운 형태로 컴퓨터에 명령을 표현하는 프로그래밍 언어입니다. 사람은 메모에 생략된 내용을 문맥으로 짐작할 수 있지만, Python 실행 환경은 문맥을 짐작하지 않습니다. 작성된 기호를 Python 문법에 따라 해석합니다.

Python 실행 환경은 우리가 작성한 코드를 해석하고 처리합니다. 여기서 실행은 화면에 코드를 적어두는 것이 아니라, 작성된 명령을 실제로 수행하게 하는 일입니다.

코드는 정해진 순서에 따라 실행된다

Python은 코드를 정해진 순서에 따라 위에서 아래로 실행합니다. 앞선 명령의 결과가 반영된 뒤 다음 명령을 실행합니다. 빈 줄은 코드를 읽기 쉽게 구분할 뿐, 별도의 명령으로 실행되지는 않습니다.

잠깐 확인

코드를 정확하게 작성했지만 실행하지 않았다면 출력이 생길까요? 생기지 않습니다. 작성된 코드와 실행된 코드는 구분해야 합니다.

코드를 한 줄씩 읽기

아래 코드를 아직 외울 필요는 없습니다. 각 줄이 화면에 무엇을 보여주는지 순서대로 읽는 것이 먼저입니다. 값에 이름을 붙이는 방법은 2교시에서 다룹니다.

print("이름:", "서윤")
print("전공:", "시각디자인")

값을 화면에 보여주는 기능: print()

print()는 괄호 안의 값을 출력하는 Python의 기본 기능입니다. 괄호 안에 여러 값을 쉼표로 나누어 넣으면 Python이 값 사이에 공백을 두고 함께 출력합니다.

글자 그대로 
print("서윤")

서윤

숫자 계산 결과 
print(3 + 2)

5

글자 데이터는 따옴표로 감쌉니다

print("서윤")의 따옴표는 화면에 보이지 않습니다. 따옴표는 “이 내용은 글자 데이터”라는 표시입니다. 따옴표 없이 print(서윤)이라고 쓰면 Python은 글자가 아니라 미리 정의된 이름을 찾습니다. 이름을 정의하는 방법은 2교시에서 다룹니다.

위에서 아래로 한 줄씩

명령은 위에서 아래로 실행됩니다. 위에 있는 줄을 먼저 실행한 뒤 다음 줄로 넘어가므로 줄의 순서를 바꾸면 출력 순서도 달라집니다.

이름 먼저 
print("서윤")
print("시각디자인")

결과: 서윤이 먼저, 시각디자인이 다음에 출력됩니다.

전공 먼저 
print("시각디자인")
print("서윤")

결과: 같은 값이라도 줄 순서가 바뀌면 화면 순서도 바뀝니다.

작은 기호도 명령의 일부다

따옴표나 괄호가 올바르게 닫히지 않으면 Python은 코드를 문법에 맞게 해석할 수 없습니다. 이때 나타나는 SyntaxError는 코드가 Python 문법에 맞지 않음을 알리는 오류입니다. 오류 메시지를 읽을 때는 막연히 원인을 추측하기보다, 어느 줄이 어떤 문법 규칙에 맞지 않는지부터 확인합니다.

첫 코드에서 만나는 기호의 역할
표기역할빠지거나 달라지면
"서윤"따옴표 안의 내용을 글자 데이터로 표시따옴표가 없으면 미리 정의된 이름을 찾습니다.
print(...)괄호 안의 값을 출력 기능에 전달괄호가 맞지 않으면 문법을 해석할 수 없습니다.
3과 "3"숫자와 글자를 구분같은 기호라도 처리 방식이 달라집니다.
코드의 줄 순서명령이 처리되는 순서화면에 나타나는 순서도 바뀝니다.

네 가지 기본 자료형

Python은 연산 기호뿐 아니라 그 기호가 다루는 값의 종류도 함께 확인합니다. 따라서 같은 +라도 값에 따라 결과가 달라집니다.

숫자 계산 
print(3 + 2)

5

숫자 두 개를 더합니다.

글자 연결 
print("3" + "2")

32

글자 두 개를 앞뒤로 연결합니다.

3과 2는 계산할 숫자이고, "3"과 "2"는 앞뒤로 연결할 글자입니다. 값의 종류가 다르면 허용되는 처리 방식도 달라집니다. 그 종류의 이름이 자료형입니다.

자료형은 값이 어떤 종류의 데이터인지, 그리고 그 값에 어떤 연산을 할 수 있는지를 나타냅니다.

int / integer 정수
120

소수점이 없는 수입니다. 개수, 순서, 픽셀 좌표처럼 끊어 세는 값에 사용합니다.

float / floating point 실수
0.75

소수점이 있는 수입니다. 비율, 투명도, 시간처럼 연속적으로 변하는 값에 사용합니다.

str / string 문자열
"Night Walk"

문자들이 순서대로 이어진 값입니다. 따옴표로 감싸며 이름, 제목, 색상명 같은 텍스트를 나타낼 때 사용합니다.

bool / boolean 불리언
True

참과 거짓을 나타냅니다. 가능한 값은 True와 False이며 첫 글자는 대문자입니다.

따옴표 유무에 따라 자료형이 달라진다

True는 참을 나타내는 bool이지만, "True"는 네 글자로 이루어진 str입니다. 숫자나 참·거짓 값을 따옴표로 감싸면 문자열로 처리됩니다.

비슷해 보이는 값 구분하기

20을 서로 다른 방식으로 작성했을 때의 자료형
코드에 적은 값자료형가능한 처리
20int정수 계산에 사용할 수 있습니다.
20.0float소수점이 있는 수로 계산됩니다.
"20"str글자 2와 글자 0의 묶음으로 처리됩니다.
Truebool참인 상태를 나타냅니다.

자료형 확인하기: type()

값의 자료형이 헷갈리면 추측에 머물지 않고 type()으로 확인할 수 있습니다. 값 자체를 괄호 안에 넣으면 됩니다.

print(type(20))
print(type("blue"))
print(type(True))
<class 'int'>
<class 'str'>
<class 'bool'>

출력에 보이는 class의 자세한 의미는 지금 다루지 않습니다. 이번 주에는 int, str, bool처럼 마지막에 표시되는 자료형 이름을 확인하면 충분합니다.

자료형에 따라 달라지는 연산

같은 +라도 정수끼리면 더하고, 문자열끼리면 이어 붙입니다. 연산의 의미를 파악하려면 기호와 함께 값의 자료형을 살펴야 합니다.

이번 주에 사용하는 기본 연산
코드결과설명
10 + 515정수 덧셈
10 / 25.0/로 나눈 결과는 실수
"data" + " art""data art"문자열 연결
"ha" * 3"hahaha"문자열 반복

모든 자료형을 서로 더할 수 있는 것은 아닙니다

"20" + 1처럼 문자열과 정수를 바로 더하면 + 연산을 적용할 수 없어 TypeError가 발생합니다. 두 값을 더하려면 먼저 자료형을 맞춰야 하며, 자료형 변환은 이후 수업에서 다룹니다.

Python과 Google Colab은 무엇이 다른가

Python은 코드를 작성하는 데 쓰는 프로그래밍 언어이고, Google Colab은 브라우저에서 Python 코드를 작성하고 실행하는 노트북 환경입니다. Colab 노트북에는 설명, 코드, 결과를 한 문서에 함께 남길 수 있습니다.

노트북에서는 셀의 위치와 실행 순서가 다를 수 있다

빠른 확인과 한 문장 정리

  1. 데이터와 명령의 차이를 한 문장으로 적습니다.
  2. 20, 20.0, "20", False의 자료형을 적습니다.
  3. 3 + 2와 "3" + "2"의 결과가 다른 이유를 한 문장으로 적습니다.
  4. 코드를 실행한다는 것은 ________________이다.

답을 열어 확인하기

아래 네 질문은 강의 중에 모두 다루지 않아도 됩니다. 자신의 답을 먼저 작성한 뒤 항목을 열어 핵심 내용을 확인합니다.

1. 데이터, 명령, 출력은 어떻게 다른가?

데이터는 프로그램이 처리하는 정보이고, 명령은 그 데이터로 무엇을 할지 컴퓨터에 지시하는 내용입니다. 출력은 명령을 실행한 뒤 확인할 수 있는 결과입니다.

2. 20, 20.0, "20", False의 자료형은 각각 무엇인가?

차례로 int, float, str, bool입니다. 따옴표와 소수점, True 또는 False 표기가 자료형을 구분하는 단서가 됩니다.

3. 3 + 2와 "3" + "2"의 결과가 다른 이유는?

전자는 숫자끼리 더해 5가 되고, 후자는 글자끼리 이어 붙어 32가 됩니다. 같은 +라도 값의 자료형에 따라 처리가 달라집니다.

4. "20" + 1이 TypeError가 되는 이유는?

문자열과 정수 사이에는 + 연산이 정의되어 있지 않기 때문입니다. 두 값을 더하려면 먼저 같은 자료형으로 변환해야 합니다.

2교시 예고

2교시에는 오늘 구분한 값에 나중에도 사용할 이름을 붙입니다. 이 이름을 변수라고 합니다. 변수를 이용해 같은 값을 여러 곳에서 사용하고 실행 중에 바꾸는 방법, 숫자 값이 이미지의 막대와 원으로 표현되는 과정을 살펴봅니다.
