0-5분 · 입력, 규칙, 출력을 코드로 연결하기

1주차에는 콘텐츠 프로그래밍을 입력, 규칙, 출력의 구조로 살펴보았습니다. 오늘은 그 구조가 실제 코드 안에서 어떻게 나타나는지 확인합니다.

개별 생각 · 2분

컴퓨터가 나를 소개하게 하려면?

컴퓨터 화면에 “안녕하세요. 저는 서윤이고 시각디자인을 전공합니다”라는 문장을 출력하려고 합니다. 컴퓨터에 알려줘야 할 정보와 시켜야 할 행동을 나누어 적어봅니다.

  • 정보의 예: 이름, 전공
  • 행동의 예: 정보를 문장으로 화면에 표시하기

핵심 구분

이름과 전공은 컴퓨터가 처리할 데이터이고, 화면에 표시하기는 데이터에 수행할 명령입니다. 프로그램은 이 데이터와 명령을 컴퓨터가 실행할 수 있는 정확한 순서로 작성한 것입니다.

5-15분 · 데이터와 명령은 어떻게 결과가 되는가

먼저 구분할 다섯 용어

프로그램 실행을 설명하는 기본 용어
용어뜻자기소개 코드의 예
데이터프로그램이 기억하거나 처리하는 정보이름, 전공, 좋아하는 색, 음악 감상 시간
명령컴퓨터가 수행해야 할 한 가지 행동이름을 기억하기, 문장을 화면에 표시하기
코드프로그래밍 언어의 규칙에 맞게 쓴 데이터와 명령print(name)
프로그램목적을 이루도록 순서대로 구성한 코드의 묶음정보를 저장하고 자기소개를 출력하는 전체 코드
출력코드를 실행한 뒤 확인할 수 있는 결과화면에 나타난 자기소개 문장

Python의 역할

Python은 사람이 비교적 읽기 쉬운 형태로 컴퓨터에 명령을 표현하는 프로그래밍 언어입니다. 우리가 작성한 코드는 Python 실행 환경에서 해석되고 처리됩니다. 여기서 실행은 화면에 코드를 적어두는 것이 아니라, 작성된 명령을 실제로 수행하게 하는 일입니다.

실행할 때 컴퓨터 안에서 일어나는 일

Python 코드가 처리될 때 각 요소의 역할
요소초심자 관점의 역할자기소개 코드에서 하는 일
소스 코드사람이 Python 문법으로 작성한 명령name = "서윤", print(name)
Python 실행 환경코드를 읽고 어떤 동작을 수행할지 해석대입과 출력 명령을 순서대로 처리
CPU계산과 명령 수행을 담당하는 장치값을 처리하고 출력 기능을 수행
메모리실행 중 필요한 값과 상태를 임시로 기억name에 연결된 "서윤"을 기억

실제 Python 내부에는 더 많은 단계가 있지만, 이번 주에는 코드를 해석한다, CPU가 동작을 수행한다, 메모리가 실행 중인 값을 기억한다는 흐름까지만 사용합니다.

잠깐 확인

코드를 정확하게 작성했지만 실행하지 않았다면 출력이 생길까요? 생기지 않습니다. 작성된 코드와 실행된 코드는 구분해야 합니다.

15-28분 · 첫 Python 코드를 한 줄씩 읽기

아래 코드를 아직 외울 필요는 없습니다. 각 줄이 무엇을 기억하게 하고 무엇을 출력하게 하는지 순서대로 읽는 것이 먼저입니다.

name = "서윤"
major = "시각디자인"

print(name)
print(major)

화면에 보여달라는 명령: print()

print()는 괄호 안의 값을 출력하는 Python의 기본 기능입니다. print(name)은 name이라는 글자를 그대로 출력하라는 뜻이 아니라, name에 연결된 값을 찾아 출력하라는 뜻입니다.

이름에 연결된 값 
name = "서윤"
print(name)

서윤

따옴표 안의 글자 그대로 
name = "서윤"
print("name")

name

지금은 이렇게 읽습니다

=은 왼쪽과 오른쪽이 같다는 수학 기호로 읽지 않습니다. 이 수업에서는 우선 “오른쪽 값을 왼쪽 이름으로 기억한다”라고 읽습니다. 정확한 변수와 대입의 구조는 2교시에서 다룹니다.

28-38분 · 컴퓨터는 순서와 표기를 그대로 따른다

사용하기 전에 먼저 알려주어야 한다

사람은 문맥으로 빠진 정보를 짐작할 수 있지만, 컴퓨터는 아직 실행하지 않은 다음 줄을 미리 참고하지 않습니다.

정상 순서 
name = "서윤"
print(name)

결과: 먼저 값을 기억한 뒤 사용하므로 서윤이 출력됩니다.

문제가 생기는 순서 
print(name)
name = "서윤"

결과: 첫 줄을 실행할 때 name을 아직 모르므로 NameError가 발생합니다.

작은 기호도 명령의 일부다

첫 코드에서 만나는 기호의 역할
표기역할빠지거나 달라지면
"서윤"따옴표 안의 내용을 글자 데이터로 표시서윤을 이미 정해진 이름으로 찾으려 합니다.
print(...)괄호 안의 값을 출력 기능에 전달괄호가 맞지 않으면 문법을 해석할 수 없습니다.
name기억한 값을 다시 찾기 위한 이름Name은 다른 이름으로 처리됩니다.
코드의 줄 순서명령이 처리되는 순서필요한 값이 준비되기 전에 사용하면 오류가 납니다.

같은 + 기호인데 결과가 다른 이유

Python은 기호만 보는 것이 아니라 기호의 양쪽에 있는 값의 종류도 함께 봅니다. 다음 결과를 비교해봅니다.

숫자 계산 
print(3 + 2)

5

숫자 두 개를 더합니다.

글자 연결 
print("3" + "2")

32

글자 두 개를 앞뒤로 연결합니다.

따옴표가 있는 "3"은 계산할 숫자가 아니라 글자입니다. 컴퓨터가 값의 종류를 구분하는 방식이 바로 다음 교시에서 배울 자료형입니다.

38-46분 · Python과 Google Colab은 무엇이 다른가

Python은 코드를 쓰는 언어이고, Google Colab은 브라우저에서 Python 코드를 작성하고 실행하는 노트북 환경입니다. Colab 노트북은 설명과 코드와 결과를 한 문서 안에 함께 남길 수 있습니다.

노트북에서는 셀의 위치와 실행 순서가 다를 수 있다

한 코드 셀 안의 코드는 위에서 아래로 실행됩니다. 하지만 여러 셀은 화면에 놓인 순서가 아니라 실제로 실행 버튼을 누른 순서로 런타임에 반영됩니다.

초심자가 자주 만나는 상황

아래쪽 셀에서 name = "서윤"을 먼저 실행했다면 위쪽 셀의 print(name)도 작동할 수 있습니다. 그러나 런타임을 다시 시작하면 기억한 값이 사라져 같은 코드가 오류를 낼 수 있습니다. 노트북은 가능하면 위에서 아래로 다시 실행해도 작동하도록 작성합니다.

노트북 파일과 런타임에서 보존되는 것
구분기억하는 것런타임이 종료되면
Colab 노트북 파일텍스트 셀, 코드 셀, 저장된 출력Google Drive에 저장된 문서 내용은 남습니다.
Python 런타임실행 중인 변수의 값과 임시 상태실행 중 기억한 값은 사라집니다.

print()가 없어도 값이 보이는 경우

Colab은 코드 셀의 마지막에 값이나 계산식만 적어도 결과를 보여줄 수 있습니다. 그러나 여러 결과를 명확하게 확인하고 자기소개 노트북을 읽기 쉽게 만들기 위해 이번 주에는 print()를 사용합니다.

46-50분 · 개념 확인과 다음 교시 연결

개별 확인 · 4분

빠른 확인과 한 문장 정리

  1. 데이터와 명령의 차이를 한 문장으로 적습니다.
  2. print(name)과 print("name")의 출력이 어떻게 다른지 적습니다.
  3. 3 + 2와 "3" + "2"의 결과가 다른 이유를 한 문장으로 적습니다.
  4. 코드를 실행한다는 것은 ________________이다.

수업 후 개별 복습: 답을 열어 확인하기

아래 네 질문은 50분 수업 시간에 모두 설명하지 않습니다. 자신의 답을 먼저 작성한 뒤 항목을 열어 핵심 내용을 확인합니다.

1. 데이터, 명령, 출력은 어떻게 다른가?

데이터는 프로그램이 기억하거나 처리할 정보이고, 명령은 그 정보에 수행할 행동입니다. 출력은 명령을 실행한 뒤 확인할 수 있는 결과입니다.

2. name = "서윤" 다음에 print("name")을 실행하면 무엇이 나오는가?

name이 출력됩니다. 따옴표 안의 내용은 이름을 찾아보라는 표시가 아니라 글자 그대로의 데이터입니다. 저장된 값 서윤을 출력하려면 print(name)을 사용합니다.

3. print(name)을 먼저 실행하고 다음 줄에서 name = "서윤"을 실행하면 왜 오류가 나는가?

첫 줄을 처리하는 시점에는 name이라는 이름과 값의 연결이 아직 만들어지지 않았기 때문입니다. 컴퓨터는 다음 줄을 미리 실행해 부족한 정보를 채우지 않습니다.

4. 노트북을 저장했는데 런타임을 다시 시작하면 변수 값이 사라지는 이유는?

노트북 파일은 작성한 코드와 설명을 저장하지만, 변수 값은 Python 런타임이 실행 중에 기억합니다. 런타임이 종료되면 코드는 남아 있어도 실행 중이던 값은 다시 코드를 실행해야 만들어집니다.

2교시 예고

2교시에는 값에 이름을 붙이는 변수와 값의 성격을 구분하는 자료형을 배웁니다. 숫자, 글자, 참과 거짓이 서로 어떻게 다르게 저장되고 계산되는지 확인합니다.
