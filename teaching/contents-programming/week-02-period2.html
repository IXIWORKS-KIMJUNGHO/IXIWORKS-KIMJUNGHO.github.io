0-5분 · 같은 기호가 다른 결과를 만드는 이유

1교시 마지막에 살펴본 두 코드를 다시 비교합니다. 먼저 실행 결과를 적고, 그 결과가 달라지는 이유를 한 문장으로 설명해봅니다.

예측 A 
print(3 + 2)

?

예측 B 
print("3" + "2")

?

결과와 이유 확인

첫 결과는 5, 두 번째 결과는 32입니다. 3과 2는 계산할 숫자이고, "3"과 "2"는 앞뒤로 연결할 글자입니다. 값의 종류가 다르면 허용되는 처리 방식도 달라집니다.

5-15분 · 값에 다시 사용할 이름 붙이기

값, 변수, 대입

  • 값은 프로그램이 처리하는 실제 데이터입니다. 예: 20, 3.5, "blue", True
  • 변수는 값을 다시 찾고 사용할 수 있도록 붙인 이름입니다. 예: age, favorite_color
  • 대입은 계산된 값을 변수 이름과 연결하는 동작입니다. Python에서는 =으로 표시합니다.

변수가 필요한 이유

값을 코드 곳곳에 직접 반복하면 수정할 위치가 늘어나고 각 값의 의미를 기억하기 어렵습니다. 변수는 값을 한 번 정의하고, 의미 있는 이름으로 여러 번 다시 사용하게 합니다.

값을 직접 반복 
print("이름:", "서윤")
print("작업자:", "서윤")

이름이 바뀌면 모든 위치를 찾아 수정해야 합니다.

변수를 다시 사용 
name = "서윤"
print("이름:", name)
print("작업자:", name)

처음 대입한 값 하나만 바꾸면 이후 사용 위치에도 반영됩니다.

변수 이름에는 따옴표를 붙이지 않습니다

name은 값을 찾기 위한 이름이고 "name"은 n, a, m, e라는 네 글자로 이루어진 문자열입니다. 변수 이름과 글자 데이터는 역할이 다릅니다.

15-23분 · 변수의 값은 실행 중에 바뀔 수 있다

변수는 한 번 정한 값을 영원히 보관하는 이름이 아닙니다. 새로운 값을 다시 대입하면 이후부터 그 이름은 새 값을 가리킵니다.

score = 10
score = score + 5
print(score)

수학의 등식과 다른 점

수학에서 score = score + 5는 성립하기 어렵지만, 프로그램에서는 순서가 있습니다. 오른쪽을 먼저 계산하고 그 결과를 왼쪽 이름에 다시 대입하므로 정상적인 명령입니다.

개별 추적 · 2분

마지막 값 예상하기

minutes = 30
minutes = minutes * 2
minutes = minutes + 15
print(minutes)

각 줄을 실행한 뒤 minutes의 값을 차례로 적습니다. 마지막 출력은 75입니다.

23-33분 · 네 가지 기본 자료형

자료형은 값이 어떤 종류의 데이터인지, 그리고 그 값에 어떤 연산을 할 수 있는지를 나타냅니다. 겉으로 비슷해 보여도 자료형이 다르면 Python의 처리 방식도 달라집니다.

int / integer 정수
pixel_x = 120

소수점이 없는 수입니다. 개수, 순서, 픽셀 좌표처럼 끊어 세는 값에 사용합니다.

float / floating point 실수
opacity = 0.75

소수점이 있는 수입니다. 비율, 투명도, 시간처럼 연속적으로 변하는 값에 사용합니다.

str / string 문자열
title = "Night Walk"

문자와 문장의 묶음입니다. 따옴표로 감싸며 이름, 제목, 색상명, 텍스트에 사용합니다.

bool / boolean 불리언
is_visible = True

참과 거짓을 나타냅니다. 가능한 값은 True와 False이며 첫 글자는 대문자입니다.

따옴표가 자료형을 바꾼다

True는 참을 나타내는 bool이지만, "True"는 네 글자로 이루어진 str입니다. 숫자와 마찬가지로 참·거짓도 따옴표 유무를 구분합니다.

비슷해 보이는 값 구분하기

20을 서로 다른 방식으로 작성했을 때의 자료형
코드에 적은 값자료형가능한 처리
20int정수 계산에 사용할 수 있습니다.
20.0float소수점이 있는 수로 계산됩니다.
"20"str글자 2와 글자 0의 묶음으로 처리됩니다.
Truebool참인 상태를 나타냅니다.

자료형 확인하기: type()

값이나 변수의 자료형이 헷갈리면 추측에 머물지 않고 type()으로 확인할 수 있습니다.

age = 20
favorite_color = "blue"

print(type(age))
print(type(favorite_color))
<class 'int'>
<class 'str'>

출력에 보이는 class의 자세한 의미는 지금 다루지 않습니다. 이번 주에는 int와 str처럼 마지막에 표시되는 자료형 이름을 확인하면 충분합니다.

33-41분 · 변수값이 이미지가 되는 순간

변수는 계산 결과를 출력하는 데만 쓰이지 않습니다. 프로그램이 변수값을 길이, 크기, 색, 표시 상태 같은 시각 속성과 연결하면 데이터가 이미지의 형태를 결정합니다. 아래 두 이미지는 이 대응 관계를 설명하기 위해 생성형 이미지 도구로 제작한 수업용 개념 시안이며, Python 코드의 실제 실행 화면은 아닙니다.

weekly_hours가 4에서 12로 바뀌며 초록 막대가 길어졌고, average_rating이 3.0에서 4.8로 바뀌며 파란 원이 커졌습니다. 문자열 favorite_content와 불리언 wants_to_create는 같으므로 설명과 상태 타일은 그대로입니다. 이처럼 어떤 시각 요소가 바뀌는지는 그 요소와 연결된 변수에 달려 있습니다.

41-46분 · 자료형에 맞는 연산과 읽기 좋은 이름

자료형에 따라 달라지는 연산

모든 자료형을 서로 더할 수 있는 것은 아닙니다

"20" + 1처럼 문자열과 정수를 바로 더하면 Python은 두 값을 어떤 방식으로 합쳐야 하는지 결정할 수 없어 TypeError를 발생시킵니다. 자료형 변환은 이후 수업에서 다룹니다.

설명과 값을 함께 출력하기

print()의 괄호 안에 여러 값을 쉼표로 나누어 넣으면 Python이 값 사이에 공백을 두고 함께 출력합니다. 아직 문자열 포맷 문법을 배우지 않아도 읽기 쉬운 자기소개를 만들 수 있습니다.

46-50분 · 오류를 읽고 실습 준비 확인하기

오류 화면 전체를 한 번에 이해하려고 하지 않습니다. 우선 마지막 줄에서 오류 이름과 오류 설명을 찾고, 그 위에서 문제가 발생한 코드 줄을 확인합니다.

1. name = "서윤"에서 값, 변수, 대입 기호는 각각 무엇인가?

값은 "서윤", 변수 이름은 name, 대입 기호는 =입니다. 오른쪽 값을 먼저 확인한 뒤 왼쪽 이름과 연결합니다.

2. 20, 20.0, "20", False의 자료형은 각각 무엇인가?

차례로 int, float, str, bool입니다. 따옴표와 소수점, True 또는 False 표기가 자료형을 구분하는 단서가 됩니다.

3. score = 10 다음에 score = score + 5를 실행하면 score는 얼마인가?

15입니다. 오른쪽의 기존 값 10에 5를 더한 뒤, 계산 결과 15를 같은 이름 score에 다시 대입합니다.

4. favorite color가 변수명으로 적절하지 않은 이유는?

변수명에는 공백을 사용할 수 없습니다. 수업 규칙에 따라 favorite_color처럼 단어 사이를 밑줄로 연결합니다.

3교시 연결: 자기소개 노트북의 도착점

3교시 시작 전 준비 완료 기준

  • print()에 변수 이름을 넣었을 때 어떤 값이 나오는지 예측할 수 있습니다.
  • 오류가 발생하면 마지막 줄의 오류 이름부터 확인할 수 있습니다.
