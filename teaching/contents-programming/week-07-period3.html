EXIT GATE

자동 검사 통과 + 두 파일 제출 확인 = 즉시 귀가

예시와 같은 디자인을 만들 필요가 없습니다. 조건을 충족한 자신의 구성 한 장을 제출하면 필수 실습을 완료한 것입니다.

귀가 조건: 제출 전에 열 가지 확인

  1. 노트북 파일명week07_학번_이름.ipynb 형식으로 변경했습니다.
  2. 제출 정보학번, 이름 또는 별명, 20자 이상의 구성 의도를 작성했습니다.
  3. 원본 선택자신의 6주차 PNG 또는 수업용 대체 이미지가 정상적으로 열립니다.
  4. 출처 기록제목, 창작자, 원본 주소, 라이선스, 변형 내용을 모두 작성했습니다.
  5. 자르기원본 전체보다 작은 유효한 crop_box를 선택했습니다.
  6. 변형 레이어자르기·크기 변경·회전을 적용한 레이어를 세 개 만들었습니다.
  7. 회전과 알파음수와 양수 각도를 모두 사용하고 서로 다른 알파 값을 두 가지 이상 사용했습니다.
  8. 위치와 캔버스세 위치가 서로 다르며 모든 레이어가 1000 × 1000 RGBA 캔버스 안에 들어옵니다.
  9. 전체 재실행새 세션에서 모두 실행했을 때 완료 문구와 최신 PNG가 확인됩니다.
  10. 두 파일 제출실행 결과가 포함된 .ipynb와 week07_학번_이름.png를 제출했습니다.

자동 검사는 작품의 미적 취향을 채점하지 않는다

검사 셀은 파일명, 출처 기록, 자르기 범위, 레이어 수, 각도, 알파, 위치, 캔버스 크기, PNG의 최신 상태만 확인합니다. 어떤 색이 더 아름다운지, 어느 구도가 더 좋은지는 하나의 정답으로 판정하지 않습니다.

STEP 1: 수정 전 기준 실행

처음에는 값을 바꾸지 않고 STEP 0부터 STEP 4까지 순서대로 실행합니다. 수업용 원본, 원본 전체를 자른 미리보기, 같은 위치에 겹친 세 레이어, 저장된 PNG가 차례로 보이면 환경은 정상입니다. 시작값은 일부러 완료 조건을 통과하지 않도록 되어 있습니다.

CHECK 01

STEP 0의 수업용 원본과 STEP 3의 기본 합성, STEP 4의 저장 파일이 모두 보이면 수정 준비를 완료했습니다.

NameError가 나오거나 이미지가 보이지 않을 때

오류가 난 셀만 반복하지 않습니다. STEP 0부터 위에서 아래로 다시 실행합니다. FALLBACK_SOURCE_PATH, Image, canvas가 정의되지 않았다는 메시지는 앞 셀이 실행되지 않았다는 뜻입니다.

STEP 2: 제출 정보와 원본 기록

STEP 1 코드 셀에서 학번, 이름, 구성 의도를 작성합니다. PNG 파일명은 입력한 학번과 이름으로 자동 생성됩니다.

student_id = "20260000"
student_name = "김민지"
composition_intent = "서로 다른 방향의 조각이 중앙에서 겹치며 바깥으로 시선을 이끈다."
output_filename = f"week07_{student_id}_{student_name}.png"

수업용 대체 이미지를 사용한다면 아래 출처 값은 그대로 둡니다. 자신의 6주차 결과물을 사용할 때는 Colab에 PNG를 업로드하고 source_choice = "own", source_path = "업로드한_파일.png"로 바꿉니다. 자신이 만든 이미지라도 제목, 창작자, 원본 주소 또는 자신의 파일 표기, 이용 근거, 변형 내용을 남깁니다.

source_choice = "provided"
source_path = FALLBACK_SOURCE_PATH
source_title = "Week 07 Source Poster"
source_creator = "Course-provided asset"
source_url = "Bundled in the Week 07 notebook"
source_license = "Course use / provided asset"
change_description = "자르기, 크기 변경, 회전, 투명도 조절과 레이어 합성"
CHECK 02

셀 아래에 제출자, 구성 의도, 원본 기록, 변형 내용이 자신의 선택과 일치하게 출력됩니다.

파일명 검사에서 멈출 때

output_filename 줄을 직접 다른 문자열로 바꾸지 않습니다. 학번과 이름을 수정한 뒤 셀을 다시 실행하면 week07_학번_이름.png가 자동으로 만들어집니다. 노트북 파일명도 같은 학번과 이름을 사용합니다.

자신의 6주차 PNG를 사용하고 싶을 때

Colab 왼쪽의 폴더 아이콘을 누르고 업로드 아이콘으로 PNG를 올립니다. 표시된 파일명을 복사해 source_path의 따옴표 안에 붙여 넣습니다. 세션을 다시 시작하면 업로드 파일이 사라질 수 있으므로 최종 전체 실행 전에 다시 업로드합니다.

FileNotFoundError 또는 파일을 찾을 수 없다는 안내가 나올 때

source_path의 철자, 공백, 확장자, 대소문자를 Colab 파일 목록과 비교합니다. 수업용 원본으로 돌아가려면 source_choice = "provided", source_path = FALLBACK_SOURCE_PATH로 복구하고 STEP 0부터 다시 실행합니다.

STEP 3: 원본보다 작은 영역 자르기

STEP 2의 시작값 (0, 0, working_image.width, working_image.height)는 원본 전체를 선택합니다. 왼쪽·위·오른쪽·아래 경계를 숫자로 바꾸어 더 작은 영역을 선택합니다. 수업용 원본은 900 × 900입니다.

# 예시일 뿐이며 다른 유효한 영역을 선택할 수 있습니다.
crop_box = (140, 120, 760, 780)
  • 0 ≤ left < right ≤ 원본 너비를 만족합니다.
  • 0 ≤ top < bottom ≤ 원본 높이를 만족합니다.
  • 결과 너비는 right - left, 높이는 bottom - top입니다.
  • 원본 전체와 같은 크기가 아니라 실제로 일부를 선택합니다.
CHECK 03

자른 미리보기에서 원본의 일부만 보이고, 출력된 미리보기 크기가 원본 크기와 다릅니다.

자른 이미지가 비어 있거나 매우 작게 보일 때

right가 left보다, bottom이 top보다 충분히 큰지 확인합니다. 처음에는 각 방향의 차이가 300픽셀 이상인 영역을 선택하면 결과를 확인하기 쉽습니다.

STEP 4: 각도와 알파 값으로 세 레이어 구분

STEP 3 셀에서 세 목록만 수정합니다. angles에는 음수와 양수를 모두 넣고, 적어도 두 각도는 0이 아니어야 합니다. alphas는 100부터 240 사이의 정수이며 최소 두 값이 달라야 합니다.

# 예시: 범위와 구조를 참고하고 자신의 값을 선택합니다.
angles = [-16, 19, -6]
alphas = [150, 190, 225]
편집 가능한 값의 범위와 의미
값허용 범위화면에서 달라지는 것
angles-30부터 30, 음수와 양수 포함레이어의 방향과 회전 후 실제 경계
alphas100부터 240, 서로 다른 값 두 가지 이상아래 레이어가 비치는 정도
positions서로 다른 정수 (x, y) 세 쌍캔버스에서 레이어가 놓이고 겹치는 위치

세 레이어의 목표 크기는 (420, 420), (340, 340), (260, 260)으로 준비되어 있습니다. 회전하면 실제 경계가 더 커질 수 있으므로 셀 아래에 출력되는 실제 레이어 크기를 위치 계산에 사용합니다.

음수와 양수 각도 검사에서 멈출 때

예를 들어 [-12, 0, 18]처럼 0보다 작은 값과 큰 값을 하나 이상씩 사용합니다. 세 값 모두 0이거나 모두 양수이면 방향 비교 조건을 충족하지 않습니다.

알파 값 검사에서 멈출 때

세 값을 정수로 작성하고 각 값이 100~240 범위인지 확인합니다. [180, 180, 180]은 범위에는 맞지만 모두 같으므로 [140, 180, 220]처럼 최소 두 값을 다르게 만듭니다.

STEP 5: 세 위치로 겹침 설계

positions의 각 튜플은 해당 레이어 왼쪽 위 모서리의 캔버스 좌표입니다. 처음부터 세 값을 동시에 바꾸지 말고 가장 큰 레이어부터 한 장씩 놓습니다.

# 회전 각도에 따라 실제 크기가 달라지므로 실행 결과를 확인합니다.
positions = [(40, 70), (540, 110), (345, 555)]
  1. 첫 번째 레이어를 왼쪽 위 또는 중앙에 놓고 셀을 실행합니다.
  2. 두 번째 레이어를 첫 번째와 일부 겹치되 캔버스 안에 놓습니다.
  3. 세 번째 레이어로 비어 있는 영역과 겹치는 영역의 균형을 조정합니다.
  4. 각 위치에 실제 레이어 너비와 높이를 더해 1000을 넘지 않는지 확인합니다.
CHECK 04

세 레이어가 서로 다른 위치에서 구분되고, 일부가 겹치며, 어느 레이어도 캔버스 경계 밖에서 잘리지 않습니다.

레이어가 캔버스 안에 들어오지 않는다는 오류가 날 때

셀 아래의 실제 레이어 크기를 확인합니다. 예를 들어 실제 너비가 470이고 x가 560이면 합계가 1030이므로 오른쪽이 잘립니다. x를 530 이하로 줄입니다. y도 같은 방식으로 실제 높이와 더해 1000 이하인지 확인합니다.

세 레이어가 보이지만 모두 한곳에 겹칠 때

positions의 세 튜플이 같은지 확인합니다. 각 레이어의 왼쪽 위 좌표를 최소 100픽셀 이상 다른 방향으로 옮긴 뒤 다시 실행합니다. 자동 검사는 세 위치가 서로 다른지도 확인합니다.

STEP 6: PNG 저장과 최신 상태 확인

각도, 알파, 위치를 마지막으로 바꾼 뒤 STEP 3 합성 셀을 다시 실행하고, 바로 이어서 STEP 4 저장 셀을 실행합니다. 저장 코드는 수정하지 않습니다.

canvas.save(output_filename)

화면의 이미지와 저장 파일은 자동으로 함께 바뀌지 않는다

값을 바꾸어 화면의 canvas를 새로 만들었더라도 저장 셀을 다시 실행하지 않으면 PNG에는 이전 결과가 남습니다. 최종 수정 뒤에는 합성 → 저장 → FINAL CHECK 순서를 지킵니다.

PNG가 최신 상태가 아니라는 오류가 나올 때

현재 메모리의 canvas와 저장된 PNG 픽셀이 다르다는 뜻입니다. STEP 3의 레이어 합성 셀을 실행하고 바로 이어서 STEP 4 저장 셀을 실행한 뒤 FINAL CHECK를 다시 실행합니다.
