준비 순서

앞 단계의 통과 기준을 확인한 뒤 다음으로 갑니다. 오류가 나면 같은 버튼이나 승인을 반복하지 말고 맨 아래 도움 요청 양식을 사용하세요.

01

시작 조건을 확인합니다

설치보다 먼저 권한과 계정을 확인합니다.

  1. 이 노트북에 프로그램을 설치할 수 있는지 확인합니다.
  2. ChatGPT, GitHub, Vercel에 사용할 이메일과 비밀번호를 준비합니다.
  3. 브라우저, Codex 앱, 파일 창을 열어 둡니다.
공용 컴퓨터라면 수업이 끝난 뒤 Codex와 Vercel에서 반드시 로그아웃합니다.

브라우저 · 계정 로그인 화면

02

Codex 앱을 설치하고 로그인합니다

프로젝트 폴더 안에서 함께 일할 코딩 에이전트입니다.

macOS · 공식 앱 다운로드 페이지에서 macOS용 앱을 내려받아 설치합니다.

Windows · 공식 앱 다운로드 페이지에서 Windows용 앱을 내려받아 설치합니다.

  1. 설치한 앱을 열고 Continue to sign in을 선택합니다.
  2. 브라우저에서 ChatGPT 계정으로 로그인한 뒤 앱으로 돌아옵니다.
  3. 앱 위쪽의 메뉴에서 Codex를 선택합니다.
이름이 달라도 맞습니다 공식 다운로드 페이지에서는 ChatGPT 데스크톱 앱으로 안내합니다. 앱 안에서 Codex를 선택해 사용합니다.
지금 보는 곳

브라우저에서 다운로드·로그인 → Codex 앱

03

내 프로젝트 폴더에서 첫 응답을 확인합니다

설치만 끝내지 않고 실제 작업 위치에서 한 번 대화합니다.

  1. Finder에서 my-small-service 폴더를 만듭니다.
  2. Codex 앱에서 Cmd + O를 누릅니다.
  3. 방금 만든 폴더를 선택해 엽니다.
  1. 파일 탐색기에서 my-small-service 폴더를 만듭니다.
  2. Codex 앱에서 Ctrl + O를 누릅니다.
  3. 방금 만든 폴더를 선택해 엽니다.

Codex 입력창에 아래 문장을 붙여 넣습니다.

이 폴더에 무엇이 있는지 설명해 줘. 파일은 아직 만들거나 바꾸지 마.
지금 보는 곳

파일 창에서 폴더 만들기 → Codex 앱에서 폴더 열기

04

Codex에게 개발 환경을 확인해 달라고 합니다

명령은 직접 입력하지 않고, 확인할 내용과 결과만 읽습니다.

입력창 아래 권한 메뉴에 Ask for approval이 보이면 선택한 뒤, 아래 문장을 Codex 입력창에 붙여 넣습니다. 해당 메뉴가 보이지 않으면 설정을 바꾸지 말고 그대로 진행합니다.

이 폴더에서 웹 프로젝트를 만들 준비가 되었는지 확인해 줘. Node.js, npm, Git의 설치 여부와 버전만 확인해. 파일이나 설정은 만들거나 바꾸지 말고, 프로그램도 설치하지 마. 명령을 실행하기 전에는 무엇을 확인하는지 쉬운 말로 설명하고 내 승인을 기다려. 결과는 ‘준비됨 / 설치 필요 / 확인 실패’로 나눠 표로 보여 줘.
승인 창이 나오면 버전을 확인하는 작업인지 설명을 먼저 읽습니다. 설치·삭제·설정 변경이라고 적혀 있으면 승인하지 말고 멘토를 부릅니다.
설치 필요가 나오면 혼자 해결하지 않습니다. 결과 화면을 멘토에게 보여 주세요. 멘토는 Node.js와 Git 공식 설치 페이지를 사용합니다.

Codex 앱 · 필요한 경우 앱의 승인 창

05

Vercel 계정에 로그인합니다

오늘은 계정만 확인합니다. 배포 도구는 아직 설치하지 않습니다.

  1. Vercel 로그인 페이지를 엽니다.
  2. 수업에 사용할 이메일 또는 GitHub 계정으로 로그인합니다.
  3. 대시보드가 열리는지 확인합니다.
배포는 나중에 서비스를 공개할 때 Codex가 필요한 작업을 제안하고, 학생은 설명을 읽은 뒤 승인합니다.

목표 통과
