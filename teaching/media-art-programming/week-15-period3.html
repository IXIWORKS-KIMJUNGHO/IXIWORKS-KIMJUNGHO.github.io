라운드 2 면담

2교시와 동일한 구조로 진행됩니다. 한 명당 5~6분, 자기 보고 1분 → 진단 2~3분 → 다음 단계 합의 1~2분.

2회차 면담 슬롯

라운드 1에서 이미 면담했는데 작업하다 새 질문이 생긴 경우, 3교시 마지막 5~10분에 자유 슬롯을 운영합니다. 한 명당 2~3분으로 짧게 가능합니다.

16주차 운영 방식 미리 알기

다음 주 16주차는 제출 + 작품 감상 시간입니다.

  1. 시연영상은 수업 시작 전까지 미리 업로드 — 당일 업로드는 불가능합니다
  2. 수업 시간에는 작품 감상 — 운영 방식은 강사 안내에 따릅니다 (전체 시연 / 갤러리 / 우수작 발표 등)
  3. 당일 추가 작업 시간 없음 — 모두 미리 완성해서 옵니다

막판 체크리스트

다음 주 제출 전에 반드시 확인해야 할 항목입니다.

Edit 권한 테스트 필수

본인 계정에서는 보이는데 다른 계정에서는 못 보는 경우가 매년 있습니다. 친구 계정으로 한 번 열어봅니다.

응급 질문 채널

주말에 막히면 혼자 끙끙대지 않습니다. 다음 채널로 질문할 수 있습니다.

채널 응답 가능 시간
[이메일 / LMS 메시지 — 강사 안내] [평일 저녁 / 주말 오전 — 강사 안내]
30분 막히면 질문

일주일을 막힌 채로 보내지 않습니다. 30분 동안 진전이 없으면 바로 질문합니다.

질문할 때 포함할 내용입니다.

  1. 무엇을 하려는지 (목표)
  2. 어떤 코드를 짰는지 (스케치 링크 또는 코드 일부)
  3. 어떤 에러/현상이 나오는지 (스크린샷이면 더 좋음)
  4. 이미 시도해본 것 (있다면)

학기 마무리

1주차에 첫 캔버스에 ellipse(200, 200, 50, 50) 한 줄을 그렸던 것이 14주 전입니다.

지금은 소리를 분석하고, 수백 개의 파티클을 관리하고, 데이터를 시각화하는 코드를 쓸 수 있습니다.

기말 프로젝트는 본인이 한 학기 동안 무엇을 배웠는지 본인에게 증명하는 작업입니다. 완벽보다 본인의 흔적이 중요합니다.

3교시 핵심 요약

  1. 16주차는 제출 + 감상 시간 — 당일 추가 작업 시간 없음
  2. 막판 체크리스트 6항목을 주말 전에 통과시킵니다
  3. Edit 권한 공유 테스트는 친구 계정으로 한 번 해봅니다
  4. 막히면 30분 안에 응급 질문 채널로 묻습니다
  5. 완벽보다 본인의 흔적이 중요한 작업입니다
