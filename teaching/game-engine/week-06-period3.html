실습 과제

카메라 1대로 촬영할 시네마틱 환경 레벨 1개를 제작합니다. 컨셉 → 블록아웃 → 에셋 교체 순서로 진행합니다.

실습 제약 조건

항목 조건
레벨 크기 카메라가 바라보는 한 방향만. 가로 50m × 세로 30m 정도
카메라 1대. 이 카메라에 보이는 곳만 만들면 됩니다
에셋 수 5~10종. 같은 에셋을 크기/회전 바꿔서 반복 배치 가능
제출물 프로젝트 파일 + 뷰포트 스크린샷 3장 (카메라 앵글 1장 포함)
영화 세트장처럼 만드세요

360도 전체 공간을 제작할 필요는 없습니다. 카메라에 보이는 범위를 우선 제작합니다. 뒤쪽 영역은 비워두어도 문제 없습니다.

테마 선택

컨셉이 안 떠오르면 아래에서 고르세요. 자유 주제도 가능합니다.

테마 어디 언제 느낌 핵심 구조
A. 사막 협곡 사암 절벽 사이 석양 경이로움 양쪽 벽 + 좁은 길 + 원경
B. 숲속 폐허 이끼 낀 돌담 유적 새벽 안개 신비로움 돌담 아치 + 나무 + 안개
C. 해안 절벽 바다가 보이는 절벽 위 흐린 낮 고독함 절벽 끝 + 바위 + 먼 수평선
D. 자유 선택 직접 정하기 직접 정하기 직접 정하기 —
어떤 테마를 고르든

세 단어(어디/언제/느낌)는 먼저 정하고 시작하세요. 컨셉 없이 만들면 방향을 잃습니다.

진행 순서

순서 1: 컨셉 + 레퍼런스 (3분)

  1. 위 테마 표에서 하나를 고르거나 자유 주제를 정하세요
  2. ArtStation/Pinterest/Google에서 레퍼런스 2~3장 수집하세요
  3. 폰이나 브라우저에 띄워놓으세요 — 작업하면서 계속 참고합니다

완료 기준: 레퍼런스 이미지가 화면에 떠 있는 상태

순서 2: 레벨 생성 + 라이팅 (3분)

  1. File > New Level > Basic 으로 새 레벨을 만드세요
  2. 5주차에서 배운 Env. Light Mixer 로 라이팅을 세팅하세요
  • Window > Env. Light Mixer
  • Directional Light, SkyAtmosphere, SkyLight, Fog, Cloud 전부 Create
  • SkyLight → Mobility: Movable, Real Time Capture 체크

완료 기준: 빈 레벨에 하늘과 빛이 구성된 상태

순서 3: 블록아웃 (10분) — 가장 중요!

Modeling Mode > Create > Box로 회색 도형을 배치해서 레벨 뼈대를 잡습니다.

단계 도형 Scale 예시 역할
1. 바닥 Box 1개 X:50, Y:30, Z:0.5 지면
2. 메인 구조물 Box 2~3개 X:50, Y:3, Z:20 양쪽 벽/절벽 (테마에 따라 다름)
3. 원경 Box 1~2개 X:100, Y:100, Z:30 멀리 보이는 산/배경. 크게 만들어서 멀리 배치
4. 전경 Box 2~3개 X:1, Y:0.5, Z:2 카메라 앞의 바위/풀. 프레임 역할
블록아웃 핵심
  • 도형 7~8개면 충분합니다
  • 벽을 완전히 평행하게 놓지 말고 약간 벌리면 원근감이 강해집니다
  • 크기는 이후에 조절할 수 있으므로 대략적인 규모부터 설정하세요

완료 기준: 회색 도형으로 레벨 뼈대가 잡힌 상태

순서 4: 블록아웃 확인 (2분)

카메라가 볼 위치로 이동해서 아래 3가지를 확인합니다.

체크 확인 항목 안 되면
확인 소실점 — 시선이 한 곳으로 모이는가? 벽/구조물의 각도를 조절하세요
확인 3레이어 — 전경/중경/원경이 있는가? 없는 레이어의 도형을 추가하세요
확인 3분할 — 메인 구조물이 정중앙이 아닌 교차점 근처에 있는가? 위치를 약간 이동하세요

완료 기준: “구조가 적절하다”는 판단을 완료한 상태

순서 5: 에셋 교체 (12분)

블록아웃 도형 위에 실제 에셋을 올립니다.

  1. Content Browser에서 5주차에 받아놓은 에셋 또는 Fab 에셋을 찾으세요
  2. 블록아웃 도형 근처에 에셋을 배치하세요
  3. 블록아웃 도형을 선택 → Details 패널 → Hidden In Game 체크 (숨기기)
  4. 에셋의 크기/위치를 블록아웃에 맞게 조절하세요
  5. 반복하면서 레벨을 채우세요
에셋 배치 핵심
  • 같은 바위를 Scale과 Rotation만 바꿔서 여러 개 놓으면 충분히 다양해 보입니다
  • 불규칙하게 배치하세요. 같은 크기, 같은 간격은 자연스럽지 않습니다
  • 에셋 10종 받으려고 시간 쓰지 마세요. 3~5종이면 충분합니다

완료 기준: 실제 환경의 형태가 드러나기 시작한 상태

순서 6: 마무리 (5분)

  1. 콜리전 확인: 뷰포트 Show > Collision 체크 → 녹색 와이어프레임 확인
  2. 라이팅 미세 조절: Directional Light 회전(Ctrl+L)으로 시간대 맞추기
  3. 스크린샷 3장: 카메라 앵글 1장 + 다른 각도 2장
스크린샷 팁
  • 5주차에서 배운 HighResShot 사용 가능 (Cmd 창 > HighResShot 2048x2048)
  • 뷰포트를 F11로 전체화면 전환 후 촬영하면 더 깨끗합니다

과제 3 안내

항목 내용
과제 시네마틱용 환경 레벨 제작
제출물 프로젝트 파일 + 뷰포트 스크린샷 3장 (카메라 앵글 1장 포함)
마감 (마감일 안내)

제출 기준:

기준 내용 비중
컨셉 일관성 어디서/언제/어떤 느낌이 레벨에서 느껴지는가 25%
레벨 구조 블록아웃 기반 구성, 소실점/시선유도가 있는가 25%
깊이감 전경/중경/원경 3레이어가 있는가 25%
에셋 활용 에셋이 자연스럽고 불규칙하게 배치되었는가 25%
실습 중 흔한 문제
  • 블록아웃 없이 에셋부터 놓고 있다면? → Modeling Mode > Box로 구조부터 잡으세요
  • 컨셉 없이 시작했다면? → 테마 표에서 A를 고르세요. 먼저 시작점을 정하는 것이 중요합니다
  • Modeling Mode를 찾기 어렵다면? → 에디터 상단 모드 드롭다운 → Modeling → Create → Box
  • 에셋이 같은 크기/간격으로 배치되어 있다면? → Scale, Rotation을 각각 다르게 바꾸세요
  • 깊이감이 안 느껴진다면? → 바위를 Scale 5~10배로 키워서 멀리 놓으세요. 원경이 됩니다
  • Fab 에셋을 받기 어렵다면? → 5주차에서 받아놓은 에셋을 재활용하세요
