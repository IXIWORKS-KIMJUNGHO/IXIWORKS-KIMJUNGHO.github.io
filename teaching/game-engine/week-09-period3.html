  2. Cine Camera 파라미터와 시퀀서 키프레임을 결합하는 워크플로우를 익힐 수 있다
  3. 거리와 Focal Length가 동시에 변할 때 만들어지는 영화적 효과를 체감할 수 있다

3교시는 학생 주도 실습입니다. 1·2교시에서 따라했던 Dolly Zoom을 본인 6주차 레벨에서 직접 재현합니다.

조작 절차를 익히는 시간

오늘 실습은 완성도를 점수로 나누는 시간이 아닙니다. 시퀀서 조작 절차를 익히기가 목적입니다. 완성도보다 끝까지 한 번 시도해보는 게 중요합니다.

실습 미션

본인이 6주차에 만든 레벨에서, 시네 카메라로 15초짜리 Dolly Zoom 단일 샷을 만드세요.

완성 모습

카메라가 천천히 뒤로 빠지면서, 동시에 화각이 좁아집니다(망원으로). 인물(또는 핵심 액터)의 크기는 거의 그대로인데, 배경만 점점 늘어나거나 압축되는 기괴한 효과가 보입니다. 이게 히치콕이 〈현기증〉에서 처음 쓴 Dolly Zoom입니다.

완성 체크리스트 — 4개

#조건확인
1Level Sequence 생성 + 시네 카메라 트랙 추가미확인
2Transform 키프레임 시작/끝 추가 (카메라 가까이→멀리)미확인
3Focal Length 키프레임 시작/끝 추가 (24mm → 85mm)미확인
4재생 시 Dolly Zoom 효과 시각적으로 확인 가능미확인

4개가 모두 되면 진행 확인을 요청하세요. 정확히 안 맞아도 됩니다. 시도하고 결과를 본 게 중요합니다.

단계 0: 환경 점검

본인 6주차 레벨이 열려있고, Dolly Zoom 효과가 보일 만한 씬 구성이 되어 있는지 확인합니다.

환경 점검 체크리스트

  1. 본인 6주차 레벨이 열려있나요?
  2. 카메라 워크할 공간이 있나요? (전경/중경/원경이 보이는 각도)
  3. Focus 타겟이 될 핵심 액터가 있나요? (메가스캔 식물, 바위, 캐릭터 등 두드러지는 오브젝트)
  4. 라이팅이 빌드되어 있나요? (어두운 씬에서는 효과가 잘 보이지 않음)
단조로운 평지에선 효과가 안 보입니다

전경/중경/원경이 한 화면에 나오는 각도를 미리 찾아두세요. 핵심 액터가 카메라 앞쪽에, 다른 오브젝트나 산/건물이 뒤쪽 멀리 있어야 배경 변형이 보입니다.

레벨이 단조로운 경우 — 빠른 보강

  • 1. Place Actors > Megascans 또는 Outliner에서 메가스캔 에셋 두세 개를 다른 거리에 배치
  • 카메라 앞 (1m 이내): 큰 식물이나 바위 1개
  • 중경 (3~5m): 작은 오브젝트 몇 개
  • 원경 (10m 이상): 산, 큰 식물군 등
  • 2. 라이팅이 지나치게 어둡거나 지나치게 밝지 않은지 확인

5분 안에 셋업을 끝내고 다음 단계로 갑니다.

단계 1: 시퀀스 생성 + 카메라 트랙 추가

2교시 핵심1·2에서 따라한 절차 그대로입니다.

1-1. Level Sequence 만들기

  • 1. Content Browser에서 빈 공간 우클릭
  • 2. Cinematics > Level Sequence 선택
  • 3. 이름: LS_Week09_Practice
  • 4. 더블클릭하여 시퀀서 에디터 열기

1-2. 시퀀스 길이 설정

  • 1. 시퀀서 에디터 우측 상단 End 박스에 450 입력 (15초)
  • 2. View Range도 같이 0~450으로 통일

1-3. 시네 카메라 추가

  • 1. 본인 레벨에서 CineCameraActor 선택 (없으면 Place Actors > 검색 'cine'으로 새로 배치)
  • 2. 시퀀서 에디터 좌측 상단 + Track 클릭
  • 3. Actor To Sequencer > Add 'CineCameraActor' 선택
  • 4. Transform / CineCameraComponent 두 하위 트랙 보이는지 확인 (▶ 클릭하여 펼침)

1-4. 시퀀서 카메라 시점 켜기

  • 1. 시퀀서 트랙의 CineCameraActor 줄 옆 카메라 아이콘 클릭
  • 2. 뷰포트가 카메라 시점으로 잠김

1-5. Filmback 통일

  • 1. Outliner에서 CineCameraActor 선택
  • 2. Details 패널 검색창에 filmback
  • 3. 35mm Academy 선택

여기까지 하고 손을 한 번 들어주세요. 진행 상태를 빠르게 확인하고 다음 단계로 갑니다.

단계 2: 트랜스폼 키프레임

카메라가 피사체에 가까운 위치에서 점점 멀어지는 무빙(Dolly Out)을 만듭니다.

2-1. 시작 위치 잡기

  • 1. 시퀀서에서 플레이헤드를 0프레임으로 이동 (Home 키)
  • 2. 뷰포트(파일럿 모드)에서 카메라를 핵심 액터에 가까이 이동
  • 우클릭 + WASD로 시점 이동, 마우스 드래그로 회전
  • 핵심 액터가 화면 중앙에, 적당한 크기로 보이게
  • 3. 시퀀서 트랙의 Transform 옆 + 버튼 클릭 → 시작 키프레임을 추가힘
  • 노란 다이아몬드가 0프레임에 나타나면 시작 키가 들어간 상태

2-2. 끝 위치 잡기

  • 1. 시퀀서에서 플레이헤드를 450프레임으로 이동 (End 키)
  • 2. 뷰포트에서 카메라를 핵심 액터에서 뒤로 빼서 멀리 이동
  • 우클릭 + S 키로 뒤로 이동
  • 약 2~3배 정도 거리 차이가 나도록
  • 3. Transform 옆 + 버튼 클릭 → 끝 키프레임을 추가힘

2-3. 재생해서 확인

  • 1. 시퀀서 재생 버튼 클릭 또는 스페이스바
  • 2. 카메라가 부드럽게 가까운 위치에서 먼 위치로 이동하는지 확인

이 단계에서 종료하면 결과는 Dolly Out입니다. Dolly Zoom이 되려면 다음 단계 Focal Length가 필요합니다.

흔한 문제
증상원인해결
카메라가 움직이지 않아요키프레임이 한 개만 추가됨0프레임 + 450프레임 두 위치 모두 + 버튼
두 키프레임을 추가았는데도 같은 화면시작과 끝 위치가 같음끝 프레임에서 카메라를 충분히 멀리 옮기기
카메라 시점이 아니라 일반 시점시퀀서 카메라 아이콘 꺼짐트랙 옆 카메라 아이콘 다시 클릭
핵심 액터가 화면에서 사라짐카메라가 지나치게 멀어졌거나 회전됨끝 위치에서도 핵심 액터가 화면 중앙에 보이도록 카메라 회전 조정

단계 3: Focal Length 키프레임

Dolly Zoom의 핵심. 카메라가 멀어지는 동안 화각을 좁혀(망원으로 갈수록) 피사체 크기를 유지합니다.

3-1. Focal Length 트랙 펼치기

  • 1. 시퀀서에서 CineCameraComponent 트랙 옆 ▶ 클릭하여 펼치기
  • 2. 그 안에서 Current Focal Length 트랙을 찾기
  • 안 보이면: +Track > Camera > Current Focal Length

3-2. 시작 Focal Length 키프레임

  • 1. 플레이헤드를 0프레임으로 이동
  • 2. Details 패널 또는 트랙 옆 입력 칸에 Focal Length = 24mm 입력
  • 광각이라 카메라 가까이서 핵심 액터가 화면을 채우는 정도가 적절
  • 3. Current Focal Length 옆 + 버튼 클릭 → 시작 키프레임

3-3. 끝 Focal Length 키프레임

  • 1. 플레이헤드를 450프레임으로 이동
  • 2. Focal Length를 85mm로 변경
  • 망원이라 카메라가 멀어진 위치에서도 핵심 액터가 비슷한 크기로 보이는지 확인
  • 3. + 버튼 클릭 → 끝 키프레임

3-4. 재생해서 Dolly Zoom 확인

  • 1. 스페이스바 또는 재생 버튼
  • 2. 영상이 재생되면서 다음을 확인:
  • 핵심 액터의 크기는 거의 비슷하게 유지되는가?
  • 배경의 원근감(거리감)이 변하는가? — 멀리 있던 배경이 가까이 압축되어 보이거나, 반대로 늘어나 보임
Vertigo Effect

이게 핵심 순간입니다. 처음 보면 효과를 명확히 확인할 수 있습니다. 'Vertigo Effect'라고도 불리는 이유입니다.

3-5. 안 맞으면 비율 조정

한 번에 정확히 맞지 않는 게 정상입니다. 거리 변화 비율과 Focal Length 변화 비율을 맞춰야 피사체 크기가 유지됩니다.

증상조치
끝에서 피사체가 지나치게 작게 보임Focal Length 끝값을 85 → 100~120mm로 더 길게
끝에서 피사체가 지나치게 크게 보임Focal Length 끝값을 85 → 60~70mm로 짧게, 또는 카메라를 더 멀리
시작에서 피사체가 화면에 안 들어옴Focal Length 시작값을 24 → 18~20mm로 더 광각, 또는 카메라를 더 가까이

단계 4: 재생 + 미세 조정

Dolly Zoom 기본은 만들어졌습니다. 영화 같은 느낌이 나도록 다듬는 시간입니다.

4-1. 인터폴레이션 확인

  • 1. 추가된 키프레임들 위에서 우클릭
  • 2. 인터폴레이션이 Cubic(파랑)인지 확인
  • 3. 다른 색이면 Cubic으로 변경
Cubic이 영화적인 부드러운 가속/감속을 만듭니다

Linear는 기계적, Constant는 컷처럼 즉시 변경됩니다.

4-2. 시작/끝 정지 시간 다듬기 (옵션)

  • 1. 시작 직후 1초, 끝 직전 1초 정도 카메라가 간단히 정지하면 더 영화적
  • 2. 0프레임에 더해 30프레임에도 같은 시작 위치 키프레임을 추가하면 시작 직후 1초 정지
  • 3. 마찬가지로 420프레임에 같은 끝 위치 키프레임 추가하면 끝 직전 1초 정지

이건 옵션입니다. 시간 남는 학생만 시도해보세요.

4-3. 보조 다듬기

다음 항목 중 한두 개만 골라 시도:

  • Aperture를 f/2.0~2.8로 (심도가 얕아지면 핵심 액터 더 부각)
  • Manual Focus Distance로 핵심 액터에 정확히 초점
  • 카메라 회전을 살짝 추가 (드라마틱한 무빙)

다 안 해도 됩니다. 한 가지만 시도해도 결과가 더 영화적으로 보일 것입니다.

진행 확인 + 자유 다듬기

4개 체크리스트가 다 되면 진행 확인을 요청하세요.

#확인 항목
1LS_ 프리픽스로 Level Sequence가 만들어졌는가?
2시퀀서 트랙에 Transform과 CineCameraComponent가 두 항목 모두 있는가?
3Transform / Focal Length 두 트랙에 시작/끝 키프레임이 박혔는가?
4재생 시 Dolly Zoom 효과가 보이는가? (피사체 유지, 배경 변형)

확인이 끝나면 자유롭게 다듬기 시간입니다. 단계 4의 보조 다듬기를 시도하거나, 다른 각도로 카메라 무빙을 새로 만들어봐도 됩니다.

일찍 끝낸 학생용 자율 도전
  • Rack Focus 추가: Manual Focus Distance를 시간에 따라 변경해 두 액터 사이 초점 이동
  • Aperture 키프레임: 시간이 흐르면서 심도가 변하는 효과
  • 다른 카메라 워크: 회전을 동반한 무빙, 위에서 아래로 내려오는 무빙 등

정리

오늘 시퀀서를 처음 조작 절차를 익히는 시간이었습니다. 정확히 안 맞은 학생도 괜찮습니다. 카메라가 멀어지는 동안 Focal Length가 같이 변한다는 그 감각, 두 변수가 시간에 따라 동시에 변하면서 영화적 효과가 만들어진다는 그 감각을 잡았으면 충분합니다.

오늘 만든 것은 단일 샷입니다. 카메라 한 대, 컷 하나. 10주차부터 여러 컷을 연결하는 시네마틱 흐름으로 확장합니다.

작업 파일 저장 안내

Ctrl+S로 시퀀스 + 레벨을 두 항목 모두 저장하세요.
