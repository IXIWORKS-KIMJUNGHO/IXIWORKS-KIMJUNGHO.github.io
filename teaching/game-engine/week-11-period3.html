방향 정하기 — 어떤 격투 인상을 만들 것인가

카메라를 놓기 전에 본인 격투 시퀀스가 어떤 인상으로 보이면 좋을지 먼저 정합니다.

인상어울리는 카메라 방식예시
안무가 잘 보이는 격투Wide + Rail 추적〈존 윅〉 스타일
빠르고 강한 격투짧은 멀티컷 + Closeup + Shake〈매트릭스〉, 마블 액션 스타일
캐릭터가 강해 보이는 격투Crane 부감→앙각 전환영웅 등장, 보스 등장 스타일

정답은 없습니다. 중요한 것은 본인 격투 시퀀스의 인상에 맞게 카메라를 선택하는 것입니다.

단계 1 — Cine Camera 3–5대 배치

카메라 수 정하기

10–15초 격투 시퀀스에는 4대가 가장 다루기 좋습니다. 3대도 가능하고, 콤보가 많은 경우 5대까지 늘릴 수 있습니다.

본인 격투 흐름추천 카메라 수구성
자세 비중이 큰 격투3대Wide / Medium / Closeup
펀치·킥 중심 격투4대Wide / Medium / Closeup / SideWide
콤보가 여러 번 이어지는 격투5대Wide / Medium / Closeup / SideWide / Reaction

작업 3 — 카메라 4대 생성

  • Place Actors > Cine Camera Actor 검색
  • viewport 로 드래그해 1대 배치
  • Outliner 에서 선택한 뒤 Ctrl+W 세 번으로 총 4대 만들기
  • 각 카메라 이름을 다음처럼 변경
  • CC_Wide
  • CC_Medium
  • CC_Closeup
  • CC_SideWide

작업 4 — 위치·화각 사전 배치

아래 값은 시작점입니다. 본인 캐릭터 위치와 격투 방향에 맞게 Pilot 모드로 확인하며 조정합니다.

카메라위치 예시Focal LengthAperture의도

CC_MediumX=0, Y=250, Z=13050mmf/5.6상반신, 공격 준비
CC_CloseupX=100, Y=0, Z=17085mmf/2.0얼굴·주먹·임팩트
CC_SideWideX=0, Y=-400, Z=12035mmf/5.6측면 추적, Rail 후보
위치값을 그대로 믿지 않기

위 좌표는 캐릭터가 0,0,0 근처에 있을 때의 예시입니다. 본인 캐릭터가 다른 위치에 있으면 절대좌표보다 캐릭터를 기준으로 앞/뒤/옆/높이를 보고 조정합니다.

작업 5 — 시퀀서에 4대 동시 바인딩 + Spawnable 변환

  • Outliner 검색창에 CC 입력
  • CC_Wide, CC_Medium, CC_Closeup, CC_SideWide 4대 선택
  • LS_RetargetDemo 시퀀서에서 + Add → Actor to Sequencer
  • 카메라 바인딩 4개가 추가되면, 4개 바인딩을 모두 선택
  • 우클릭 → Convert Selected Binding(s) To > Spawnable Actor
  • 시퀀서 트랙과 Outliner 의 카메라에 Spawnable 아이콘이 보이는지 확인

단계 2 — Camera Cuts + Cinematic Viewport + 4컷 구성

격투 흐름을 컷으로 나누기

가장 안정적인 기본 패턴은 다음과 같습니다.

격투 구간컷 타입길이이유

공격 시작Medium1–2초자세에서 공격으로 넘어가는 흐름

작업 6 — Camera Cuts 트랙 준비

  • 시퀀서 최상단에 Camera Cuts 트랙이 있는지 확인
  • 있으면 그대로 사용
  • 없으면 시퀀서 + Add → Camera Cut Track

작업 7 — 첫 컷: Wide

  • Camera Cuts 트랙의 + Camera → CC_Wide
  • 섹션을 0초부터 자세 잡기 끝나는 시점까지 배치
  • 예: 0초–2.5초

작업 8 — 둘째 컷: Medium

  • + Camera → CC_Medium
  • 섹션 시작점을 자세 잡기 이후로 이동
  • 섹션 끝을 임팩트 직전 1–2프레임에 맞춤

작업 9 — 셋째 컷: Closeup

  • + Camera → CC_Closeup
  • 섹션 시작점을 임팩트 직전 1–2프레임으로 이동
  • 섹션 길이는 0.5–1초 정도로 짧게 유지
  • 재생했을 때 Closeup 컷이 시작된 직후 펀치/킥이 닿으면 좋습니다

작업 10 — 넷째 컷: SideWide 또는 Wide

  • + Camera → CC_SideWide 또는 CC_Wide
  • 섹션 시작점을 임팩트 컷 직후로 이동
  • 섹션 끝을 시퀀스 끝까지 늘림

작업 11 — Cinematic Viewport + CrossHair 로 확인

  • Camera Cuts 트랙의 카메라 잠금 아이콘 또는 시퀀서 상단 카메라 아이콘으로 viewport 가 Camera Cuts 를 따라가게 설정
  • viewport 좌상단 Perspective 드롭다운 → Viewport Type > Cinematic Viewport
  • viewport 우상단 Composition Overlays → CrossHair
  • 필요하면 Letterbox Mask 2.35 체크
  • Play(Play)로 4컷 전환 확인
CrossHair 는 확인용

CrossHair 는 프레이밍을 맞추기 위한 보조선입니다. 최종 캡처 전에 꺼도 괜찮습니다. 중요한 것은 컷 정렬과 최종 화면 구성입니다.

선택 — 5번째 Reaction 컷

작업이 빠르게 끝났고 임팩트 직후 반응을 더 보여주고 싶다면 5번째 컷을 추가합니다.

  • Closeup 컷 직후 + Camera → CC_Wide 또는 별도 Reaction 카메라 선택
  • 0.5–1초 정도 짧게 배치
  • 이후 다시 마무리 컷으로 전환

단계 2 자기점검

  • [ ] Camera Cuts 트랙에 컷 4개 이상이 있다
  • [ ] Closeup 컷이 임팩트 직전 1–2프레임에 시작한다
  • [ ] 컷 사이에 빈 공간이 없다
  • [ ] Cinematic Viewport 에서 재생했을 때 카메라 전환이 따라온다

단계 3 — Rail 또는 Crane 1개 선택

Rail 과 Crane 을 둘 다 할 필요는 없습니다. 본인 격투 흐름에 맞는 것 하나를 선택합니다.

본인 격투 흐름추천이유
펀치·킥 콤보가 좌우로 이어짐Rail측면 추적 샷으로 동작 궤적이 잘 보임
정지 자세에서 강한 한 방이 나감Crane부감→앙각 전환으로 캐릭터가 강해 보임
결정하기 어려움Rail격투 시퀀스에서 가장 안정적인 선택

Rail 을 선택한 경우

작업 12R — Camera Rig Rail 생성·배치

  • Place Actors > Camera Rig Rail 검색 → viewport 로 드래그
  • Outliner 에서 이름을 Rail_FightSide 로 변경
  • 캐릭터 측면에 Rail 배치
  • Spline 양 끝점을 4–6m 정도로 조정
  • Spline 높이는 캐릭터 가슴~머리 높이(Z=130–170)에서 시작

작업 13R — 카메라를 Rail Mount 에 연결

  • Outliner 에서 Rail_FightSide 펼치기
  • RailCameraMount 또는 비슷한 이름의 Mount 확인
  • CC_SideWide 를 RailCameraMount 위로 드래그앤드롭
  • CC_SideWide 의 Relative Transform 을 0에 가깝게 Reset
  • Rail_FightSide 의 Current Position On Rail 값을 0→1 로 움직여 카메라가 따라오는지 확인

작업 14R — Rail 키프레임

  • Outliner 에서 Rail_FightSide 선택
  • 시퀀서 + Add → Actor to Sequencer
  • Rail 바인딩 트랙 옆 + Track → Current Position On Rail
  • SideWide 컷 시작 프레임에 값 0.0 키프레임
  • SideWide 컷 끝 프레임에 값 1.0 키프레임
  • 키프레임 우클릭 → Cubic 또는 Auto 로 부드럽게 조정

작업 15R — Rail 재생 확인

  • Play(Play)로 SideWide 컷 구간 확인
  • 카메라가 Rail 을 따라 미끄러지는지 확인
  • 캐릭터가 화면 밖으로 나가면 CC_SideWide 의 Look at Tracking Settings 를 켜고 타깃을 캐릭터로 지정

Crane 을 선택한 경우

작업 12C — Camera Rig Crane 생성·배치

  • Place Actors > Camera Rig Crane 검색 → viewport 로 드래그
  • Outliner 에서 이름을 Crane_FightImpact 로 변경
  • 캐릭터 옆 2–3m 위치에 Crane 본체 배치

작업 13C — 카메라를 Crane CameraMount 에 연결

  • Outliner 에서 Crane_FightImpact 펼치기
  • CameraMount 자식 확인
  • CC_Wide 를 CameraMount 위로 드래그앤드롭
  • 구조가 Crane_FightImpact > CameraMount > CC_Wide 인지 확인
Crane 에서 움직이는 대상

CC_Wide 자체를 직접 움직이기보다 Crane 본체의 Pitch / Yaw / Arm Length 를 키프레임합니다. 그래야 카메라가 Crane 의 움직임을 따라갑니다.

작업 14C — Crane 키프레임

  • Outliner 에서 Crane_FightImpact 선택
  • 시퀀서 + Add → Actor to Sequencer
  • Crane 바인딩 트랙 옆 + Track → Crane Pitch / Crane Yaw / Crane Arm Length
  • Wide 컷 시작 프레임에 다음 값으로 키프레임
  • Crane Pitch = +60
  • Crane Yaw = 0
  • Crane Arm Length = 600
  • 공격 시작 프레임에 다음 값으로 키프레임
  • Crane Pitch = -20
  • Crane Arm Length = 300
  • 키프레임 우클릭 → Cubic

작업 15C — Crane 재생 확인

  • Play(Play)로 Wide 컷 구간 확인
  • 카메라가 위에서 아래로 내려오며 캐릭터에 가까워지는지 확인
  • 캐릭터를 놓치면 CC_Wide 의 Look at Tracking Settings 를 켜고 타깃을 캐릭터로 지정

단계 4 — Keep State + Camera Shake + 선택 보너스

Keep State 적용

작업 16 — 마지막 Animation 클립 Keep State

  • 시퀀서에서 SKM_Manny > Animation 트랙의 마지막 클립 우클릭
  • Properties 클릭
  • Section > When Finished 를 Keep State 로 변경

이제 영상 끝에서 캐릭터가 T-Pose 로 돌아가는 문제를 줄일 수 있습니다.

Camera Shake 적용

작업 17 — Camera Shake 에셋 준비

  • Content Browser 에서 CS_FightImpact 또는 CameraShake 검색
  • 없으면 Content Browser 우클릭 → Blueprint Class
  • 부모 클래스 Legacy Camera Shake 선택
  • 이름을 CS_FightImpact 로 저장
  • CS_FightImpact 더블클릭 → Class Defaults 에서 값 설정
  • Oscillation Duration = 0.15
  • Rotation Oscillation > Pitch > Amplitude = 2.0
  • Rotation Oscillation > Yaw > Amplitude = 2.0
  • Location Oscillation > X > Amplitude = 5.0
  • Compile + Save
Shake 값

격투 Camera Shake 는 짧고 작게 시작하는 편이 좋습니다. 0.1–0.2초, Amplitude 1–3 범위에서 시작하고, 너무 약하면 조금씩 올립니다.

작업 18 — Camera Shake 트랙 추가

  • 시퀀서에서 CC_Closeup 바인딩 트랙 옆 + Track
  • Camera Shake 선택
  • Camera Shake 트랙 우클릭 → Add Camera Shake → CS_FightImpact
  • 추가된 섹션을 임팩트 프레임 직전 1프레임부터 직후 2프레임 정도에 배치
  • 길이는 3–4프레임, 약 0.1–0.15초 정도로 조정
  • Play(Play)로 Closeup 임팩트 순간에 흔들림이 보이는지 확인

선택 보너스 — 점프·돌진 모션 슬라이딩 줄이기

본인 격투에 점프·돌진 모션이 있고 캐릭터가 화면 밖으로 밀려난다면 둘 중 하나를 선택합니다. 슬라이딩 문제가 없으면 건너뛰어도 됩니다.

선택 A — FK Control Rig 6단계

  • Content Browser 우클릭 → Cinematics > Level Sequence → SE_AnimationEdit 생성
  • SKM_Manny + 슬라이딩이 있는 문제 모션만 단독 배치
  • SKM_Manny 바인딩 우클릭 → Bake To Control Rig > FK Control Rig
  • FKControlRig 트랙에서 pelvis/root 계열 본의 앞 방향 Location 키 확인
  • 앞 방향으로 크게 변하는 Location 키프레임을 선택 후 Delete
  • SKM_Manny 바인딩 우클릭 → Bake Animation Sequence → _Edit 버전 AS 저장
  • 원본 LS_RetargetDemo 로 돌아와 Animation 클립을 _Edit AS 로 교체

선택 B — Transform Quick Fix

  • 시퀀서의 SKM_Manny 바인딩 트랙 옆 + Track → Transform
  • 이동 모션 시작 프레임에 현재 위치 키프레임
  • 이동 모션 끝 프레임에 반대 방향 Location 키프레임
  • 예: 캐릭터가 X 방향으로 +200cm 밀리면, 끝 프레임에 X=-200 보정
  • Play(Play)로 캐릭터가 화면 안에 머무는지 확인
