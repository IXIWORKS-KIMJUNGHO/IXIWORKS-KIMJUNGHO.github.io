# Game Engine I · Week 13 Playtest Starter

이 폴더는 13주차 3교시의 개인 Alpha 플레이테스트 기록을 시작하기 위한 빈 서식입니다. Unity project나 완성된 답안을 포함하지 않습니다. 자신의 가장 최근 작동 project를 복제하고, 그 build를 `Alpha_v0`로 고정한 뒤 이 서식을 사용합니다.

## 시작 전

1. 작업 project를 `Week13_학번_이름`으로 복제합니다.
2. 시작·핵심 행동·성공 또는 실패·재시작이 가능한 build를 `Alpha_v0`로 만듭니다.
3. `playtest-template.csv`와 `ALPHA_EVIDENCE-template.md`를 자신의 제출 폴더에 복사합니다.
4. 이름 대신 Tester A·B·C만 기록합니다. 이번 수업에서는 화면이나 음성을 녹화하지 않습니다.

## 수업 중 고정할 것

- 세 명 모두 같은 Alpha v0, 소개 문장, 2분 과제와 사후 질문을 사용합니다.
- 세 테스트가 끝날 때까지 Scene, Script, UI, Audio와 build를 수정하지 않습니다.
- 관찰은 `누가 + 어느 장면에서 + 무엇을 + 몇 번 또는 몇 초 동안 했는가`의 형식으로 씁니다.
- 영향과 빈도로 문제 하나만 선택합니다. 새 mechanic은 추가하지 않습니다.
- 수정 뒤 원 테스터 한 명의 같은 과제 재검사와 기존 핵심 루프 회귀 검사를 수행합니다.

## 최종 제출 구조 예시

```text
Week13_학번_이름/
├── Alpha_v1/
├── Evidence/
│   ├── week13_학번_이름_before.png
│   └── week13_학번_이름_after.png
├── week13_학번_이름_playtest.csv
└── ALPHA_EVIDENCE.md
```

페이지의 CSV 저장 기능은 세 관찰, 문제 선택과 T01-T08 판정을 한 파일에 합칩니다. 이 starter CSV는 브라우저 기록을 사용할 수 없을 때의 대체 서식입니다.
