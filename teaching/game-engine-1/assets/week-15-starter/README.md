# Week 15 Release Starter

이 묶음은 15주차 3교시에서 RC0의 첫 실패 관문 하나를 닫고 릴리스 증거를 남기기 위한 기록 템플릿입니다. 완성 project나 정답 코드는 포함하지 않습니다.

## 시작 폴더

1. 면담에서 확인한 build를 `RC0_BASELINE/`에 복사하고 수정하지 않습니다.
2. Unity project 복사본을 `Project_RC1_WORK/`로 만듭니다.
3. 새 후보 build는 `RC1_CANDIDATE/`에 만듭니다.
4. 이 템플릿과 before, after, Player log는 `Evidence/Week15/`에 둡니다.

## 파일 역할

- `RELEASE_RECORD-template.md`: 첫 실패, 변경 계약, 판정과 남은 위험을 기록합니다.
- `release-tests-template.csv`: T01-T08의 결과와 실제 증거 위치를 기록합니다.
- `asset-ledger-template.csv`: 외부 및 생성 에셋의 출처, 허용, 수정과 최종 사용 상태를 기록합니다.
- `submission-map-template.md`: 최종 제출 항목의 실제 위치와 열기 검사를 기록합니다.

## 완료 원칙

새 기능 수나 작업 속도는 완료 조건이 아닙니다. 한 경로의 제한 변경, 같은 재검사, 전체 핵심 경로 회귀 검사와 제출 묶음 확인이 완료 조건입니다. 해결하지 못한 위험은 숨기지 않고 HOLD와 다음 검사로 기록합니다.
