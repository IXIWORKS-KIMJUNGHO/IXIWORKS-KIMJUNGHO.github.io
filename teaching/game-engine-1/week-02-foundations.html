Scene 창과 Game 창의 차이는 무엇인가요?

Scene 창은 제작자가 오브젝트를 배치하고 편집하는 공간입니다. Game 창은 활성 Camera를 통해 플레이어가 보게 될 화면입니다.

GameObject와 Component의 관계는 무엇인가요?

GameObject는 장면 속 대상의 기본 그릇이고, Component는 위치, 표시, 물리와 Script 같은 기능을 그 대상에 추가합니다.

자식의 Position이 부모를 기준으로 표시되는 이유는 무엇인가요?

부모-자식 관계가 Transform 기준을 연결하기 때문입니다. 자식의 Inspector Position은 부모에서 얼마나 떨어졌는지를 나타내는 local 좌표입니다.

Prefab과 일반 Duplicate의 가장 큰 차이는 무엇인가요?

Prefab Instance는 Project 창의 Prefab Asset과 연결됩니다. 일반 Duplicate끼리는 공통 원본이 없으므로 하나를 바꿔도 다른 복제본이 함께 바뀌지 않습니다.

막히면 증상부터 분리합니다

무작정 다시 만들기 전에 Project, Scene, Inspector, Game 또는 Console 중 어디의 문제인지 찾습니다.

Universal 2D 템플릿이 보이지 않습니다

Hub의 New project 화면에서 공지된 Editor version을 다시 선택합니다. Core 범주에서 템플릿 타일의 Download template를 완료합니다. 다른 2D 템플릿으로 임의 진행하지 않습니다.

2D Object 아래에 Square나 Circle이 없습니다

Window → Package Manager에서 2D Sprite 패키지가 설치되어 있는지 확인합니다. Universal 2D 템플릿 생성이 완전히 끝나기 전이라면 임포트 완료를 먼저 기다립니다.

Scene 창에서 오브젝트를 찾을 수 없습니다

Hierarchy에서 오브젝트를 선택하고 Scene 창에 마우스를 둔 뒤 F를 누릅니다. Inspector의 Transform 값이 지나치게 크거나 Z 값이 0이 아닌지도 확인합니다.

Scene에는 보이지만 Game에는 보이지 않습니다

Main Camera를 선택해 Game 뷰의 촬영 범위를 확인합니다. Sprite Renderer의 체크 상태, Color Alpha, Sorting Layer와 Camera의 위치도 차례로 확인합니다.

Background가 모든 오브젝트를 가립니다

Background의 Sprite Renderer에서 Sorting Layer를 Background로 되돌립니다. Z Position 이동으로 임시 해결하지 말고 Sorting Layer 설정을 수정합니다.

자식 오브젝트가 갑자기 멀리 이동했습니다

부모로 연결한 뒤 Inspector의 Position은 local 좌표입니다. 자식을 선택해 Transform을 Reset한 후 의도한 local Position을 다시 입력합니다.

Prefab 원본을 바꿔도 하나만 바뀝니다

Project 창에 파란 Prefab Asset이 있는지, Hierarchy의 대상이 Prefab Instance인지 확인합니다. 개별 Instance에 Override가 있으면 Overrides 메뉴에서 필요한 항목을 Revert합니다.

Play Mode에서 고친 값이 사라졌습니다

정상 동작입니다. Play Mode의 Scene 변경은 종료할 때 원래 상태로 돌아갑니다. 기억할 값을 기록한 뒤 Edit Mode에서 다시 적용하고 Scene을 저장합니다.

질문 형식

선택한 오브젝트 / 보고 있는 창 / 기대한 결과 / 실제 결과 / Console의 첫 빨간 오류

예: “Background의 Sorting Layer를 Background로 설정했지만 Game 뷰에서 Player가 안 보이고, Console 오류는 없습니다.”
