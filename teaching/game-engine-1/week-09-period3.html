Game Engine I / Week 09 / 3교시

하나의 세계를
세 장으로 증명하라

같은 대상과 규칙으로 후보 세 장을 만들고, 하나를 선택하고, 두 장을 거절한 이유까지 남깁니다. 결과의 화려함보다 판단의 일관성을 증명합니다.

미션 계약 확인하기 필수 테스트 8개 보기

3교시의 도착점

완성 이미지 한 장이 아니라, 같은 게임 세계를 반복해서 만들 수 있는 시각 규칙과 선택 기록을 제출합니다.

  • 01

    플레이어 역할, 장소, 핵심 행동과 목표 감정이 있는 한 문장 콘셉트를 완성합니다.

  • 02

    세 키워드, 세 금지 요소, 하나의 시점과 정확히 다섯 색을 잠급니다.

  • 03

    같은 정적 Sprite 대상의 후보를 정확히 세 장 만들고 인접 버전마다 한 변수만 바꿉니다.

  • 04

    64px·회색조·선택·출처 기준을 통과하고 제작 로그와 CSV를 저장합니다.

CLASS MODE / PERIOD 03학생 개인 목표지향 실습

목표는 고정하고 제작 경로는 선택합니다. 클릭 순서 대신 중간 도착점을 확인합니다. 교수자는 요구 조건과 판정 기준만 분명히 하고, 콘셉트·도구·프롬프트·최종 선택은 학생이 결정합니다.

미션 계약

미션: 비교 가능한 세 후보에서 하나를 선택합니다

중간평가 게임의 캐릭터·수집물·상호작용 오브젝트 중 하나를 고릅니다. 없다면 제공된 숲의 배달부 콘셉트를 사용합니다.

FIXED OUTCOME

같은 대상과 기능, 하나의 시점, 같은 형태 언어와 다섯 색을 공유하는 정적 Sprite 후보 세 장을 만들고, 필수 테스트 8개를 모두 통과한 뒤 한 장을 10주차 후처리 후보로 선택합니다.

00-60 min

  2. 05-13

  5. 39-48

  6. 48-55
    선택과 거절 기록

    채택 이유 세 개, 탈락한 두 장의 이유를 각각 한 개 이상 적습니다.

  7. 55-60
    필수 테스트와 저장

    T01부터 T08을 판정하고 파일 이름, prototype 표시와 CSV를 확인합니다.

FIXED / 모두 지킵니다

수량과 판정 기준

한 문장, 세 키워드, 세 금지 요소, 하나의 시점, 다섯 색, 같은 대상의 후보 세 장, 선택 한 장, 64px·회색조와 완전한 제작 로그를 지킵니다.

게임 대상, 장르, 도구, reference 사용 여부, prompt 언어, board 편집 도구와 작업 순서를 선택합니다. 생성 AI 대신 직접 그린 세 스케치를 사용해도 됩니다.

완료 검증

필수 테스트 8개로 완료를 증명합니다

“마음에 든다”는 판정이 아닙니다. 수량, 일관성, 작은 크기의 가독성, 선택 근거와 출처 기록을 기대 결과와 직접 비교합니다.

PASS RULE

8 / 8 PASS와 8 / 8 기록이 모두 있고, 선택 결과가 prototype candidate로 표시되며, board·선택 원본·process log가 열려야 완료입니다. 하나라도 비어 있거나 FAIL이면 해당 원인만 수정한 뒤 같은 조건으로 다시 판정합니다.

다시 생성하기 전에 board, 입력, 변경 변수와 출력 순서로 확인합니다. 원인을 찾지 못한 채 prompt를 길게 덧붙이지 않습니다.

세 후보가 서로 다른 캐릭터처럼 보입니다

대상 설명, 대표 소품, 시점, 형태 언어와 seed 지원 여부를 확인합니다. V02와 V03에 새로운 장르·재질·카메라를 추가하지 말고 바뀐 한 줄만 남깁니다.

팔레트가 결과마다 달라집니다

색 이름만 쓰지 말고 다섯 HEX와 역할을 함께 기록합니다. 참조 이미지가 있다면 style 역할과 영향 강도를 확인하고, 보드 밖의 새 강조색을 제거합니다.

64px에서 소품이 사라집니다

해상도를 높이는 것으로 해결하지 않습니다. 소품의 크기, 몸과의 겹침, 외곽과 명도 차이를 먼저 바꾸고 세부 무늬를 줄입니다.

무엇을 바꿨는지 로그로 설명할 수 없습니다

현재 버전을 보존한 뒤 마지막으로 설명 가능한 버전으로 돌아갑니다. 한 변수만 적은 새 버전을 만들고, 출력 전 기대 변화를 한 문장으로 씁니다.

참조 이미지의 출처나 허락이 불분명합니다

그 참조를 제외하고 직접 만든 형태·색 표본 또는 사용 조건이 분명한 자료로 교체합니다. “인터넷 검색”은 출처와 허락의 기록이 아닙니다.

총점은 높지만 선택이 확신되지 않습니다

10주차에 사람이 고칠 수 있는 부분과 고치기 어려운 부분을 나눕니다. 실루엣·시점처럼 구조적인 오류보다 작은 색 오차가 있는 후보가 더 좋은 handoff일 수 있습니다.

AI는 후보를 만들 수 있지만 방향과 채점은 맡지 않습니다
