6주차 3교시 / 개인 목표 실습

움직임이 읽히는
화면을 완성하라

Idle, Move, 방향, 카메라 추적과 화면 경계를 스스로 구성하고 여덟 테스트로 완료를 증명합니다.

미션 계약 읽기 8개 테스트 보기

3교시의 도착점

교수자의 화면을 재현하는 것이 아니라, 자신의 장면에서 같은 품질 조건을 만족하고 재현 가능한 증거를 남깁니다.

  • 01

    Player가 멈췄을 때 Idle, 움직일 때 Move가 체감 지연 없이 전환됩니다.

  • 02

    왼쪽·오른쪽 진행 방향이 맞고, 애니메이션이 바뀌어도 몸체와 Collider가 흔들리지 않습니다.

  • 03

    Cinemachine Camera가 Dead Zone과 Damping을 가진 채 Player를 부드럽게 추적합니다.

  • 04

    레벨의 네 끝에서 화면 밖이 보이지 않으며 필수 테스트 8개를 모두 PASS합니다.

수업 방식학생 개인 실습

교수자는 목표 확인, 질문 되묻기와 오류 범위 좁히기만 지원합니다. 학생은 작업 순서, 수치와 수정 방법을 선택하고 구현, 테스트와 기록을 직접 수행합니다.

목표는 고정하고 방법은 선택합니다

아래 결과는 모두 필요합니다. Sprite부터 정리할지, Animator부터 만들지, Camera부터 추적하게 할지는 스스로 결정합니다.

실습 계약

60분 안에 기존 2D Player에 반복되는 Idle과 Move, 좌우 방향 표현을 연결하고 Dead Zone, Damping과 Confiner 2D를 갖춘 Cinemachine Camera를 구성합니다. 완료는 Console Error 0과 필수 테스트 8개의 PASS로 판단합니다.

에셋

흔들리지 않는 Sprite

시트를 Multiple로 나누고 모든 프레임의 크기, PPU와 Pivot 기준을 일관되게 맞춥니다.

클립

두 개의 반복 Clip

Player_Idle.anim과 Player_Move.anim이 적절한 Samples로 자연스럽게 반복됩니다.

상태

입력에 반응하는 Animator

Speed Parameter와 양방향 Transition으로 Idle과 Move가 체감 지연 없이 바뀝니다.

방향

일치하는 진행 방향

왼쪽과 오른쪽 입력에서 Sprite가 이동 방향을 향하고 Collider2D 형태는 유지됩니다.

카메라

의도가 있는 추적 감각

작은 이동을 허용하는 Dead Zone과 부드러운 Damping이 있으며 카메라는 Player의 자식이 아닙니다.

경계

노출되지 않는 화면 밖

Confiner 2D가 레벨의 왼쪽, 오른쪽, 위와 아래 끝에서 화면 전체를 경계 안에 둡니다.

완료의 정의 “보기 좋아졌다”가 아니라, 다른 사람이 같은 조작으로 T01-T08을 다시 실행해 모두 같은 결과를 얻으면 완료입니다.

FAIL은 보이는 신호를 따라 좁힙니다

코드와 Inspector를 동시에 바꾸지 않습니다. 왼쪽부터 확인해 처음 끊긴 단계에서 한 가지만 수정합니다.

SPRITES→CLIPS→SPEED→STATE→FOLLOW→BOUNDARY
Clip Preview부터 흔들립니다

관찰: 각 Sprite의 Rect와 Pivot 표시를 비교합니다. 한 가지 수정: 모든 프레임의 Pivot을 같은 발 중심으로 맞춘 뒤 Apply합니다. Rigidbody2D나 Camera 값은 아직 바꾸지 않습니다.

두 Clip은 정상인데 상태가 바뀌지 않습니다

Play 중 Animator 창의 Speed 값을 봅니다. 0에서 변하지 않으면 Animator 참조와 SetFloat를, 값이 변하면 Condition, Parameter 철자와 Transition 방향을 확인합니다.

상태 전환이 늦습니다

Has Exit Time을 끄고 Transition Duration을 0에 가깝게 낮춥니다. 두 값을 동시에 바꾸었다면 하나를 되돌리고 어떤 설정이 지연을 만들었는지 기록합니다.

왼쪽에서 Player 전체가 뒤집힙니다

Player root의 Scale X를 확인합니다. 음수로 바꾸지 말고 Visual의 SpriteRenderer에 flipX를 적용합니다. Scene View에서 Collider Gizmo가 변하지 않는지 봅니다.

Camera가 너무 붙거나 늦게 따라옵니다

먼저 Dead Zone만 조절해 “언제 움직일지”를 맞춥니다. 그다음 Damping만 조절해 “얼마나 빨리 따라갈지”를 맞춥니다. Camera가 Player 자식이면 먼저 분리합니다.

한쪽 끝에서만 화면 밖이 보입니다

Game View를 유지한 채 PolygonCollider2D의 해당 쪽 꼭짓점과 Orthographic Size를 비교합니다. Bounding Shape 연결이 맞다면 경계가 화면 반쪽 크기만큼 안쪽에서 멈추는 것이 정상입니다.

코드가 컴파일되지 않습니다

Console의 가장 위 첫 빨간 오류 하나만 읽습니다. 오류 파일과 줄, 괄호, animator와 spriteRenderer 필드 선언, Parameter ID 철자를 순서대로 확인합니다.
