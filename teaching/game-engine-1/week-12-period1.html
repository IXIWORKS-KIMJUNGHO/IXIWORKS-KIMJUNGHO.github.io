Q1. AI Gateway와 MCP의 가장 큰 차이는 무엇인가?

Gateway는 Assistant 요청을 외부 agent·model provider로 전달하는 경로이고, MCP는 외부 client가 Unity Editor의 구조화된 tool을 사용하게 하는 다리입니다. 모델 선택과 Editor 도구 권한은 서로 다른 층입니다.

Q2. 연결 승인을 받았는데 왜 쓰기 승인이 또 필요한가?

연결 승인은 client가 Bridge에 접근할 수 있다는 뜻입니다. 특정 Scene·GameObject·속성을 바꿔도 된다는 작업별 허가가 아니므로 대상, 예상 차이와 복구 조건을 별도로 승인해야 합니다.

Q3. CLI가 결정론적이면 출력만 믿어도 되는가?

아닙니다. 명령 절차는 기록하기 쉽지만 잘못된 project path, 연결 상태와 버전 차이는 그대로 존재합니다. JSON·exit code와 함께 Unity의 실제 Console·Inspector 상태를 확인합니다.

Q4. API key와 접속 가능 여부는 어떻게 평가하는가?

API key는 제출하거나 화면에 보이지 않습니다. 개인 계정·유료 access도 통과 조건이 아닙니다. 연결 경로, 부분 연결 경로와 fixture 경로가 같은 권한 계약·검증표를 완성하면 같은 기준으로 평가합니다.
