하나의 에셋 키트를
게임 안에서 증명하라

네 캐릭터 프레임, 세 상호작용 Sprite, 한 UI 패널을 완성하고 기존 게임에서 움직임, 역할, UI와 전체 루프를 증명합니다.

미션 계약 확인하기 필수 테스트 8개 보기

3교시의 도착점

이미지 묶음이 아니라 기존 게임의 기능을 해치지 않고 교체 가능한 작은 아트 시스템을 제출합니다.

  • 01

    4프레임 Player, 3개 상호작용 Sprite, 1개 UI 패널의 규격을 완성합니다.

  • 02

    배경, 결함, 팔레트, 크기 중 필요한 문제를 고치고 사람의 수정 두 가지 이상을 기록합니다.

  • 03

    Sprite sheet를 분할하고 Animator와 uGUI에 연결해 실제 Game View에서 확인합니다.

  • 04

    필수 테스트 8개, CSV, 제작 로그와 45-60초 영상으로 결과를 증명합니다.

CLASS MODE / PERIOD 03학생 개인 목표지향 실습

목표는 고정하고 구현 경로는 선택합니다. 클릭 순서 대신 중간 도착점을 확인합니다. 교수자는 파일 규격과 판정 기준만 분명히 하고, 생성형 AI, 수작업, 혼합 경로, 수정 도구와 최종 표현은 학생이 결정합니다. 작업 속도와 생성 횟수는 평가하지 않습니다.

Unity AI 사용 가능 여부, 계정과 네트워크는 평가 대상이 아닙니다. 자신에게 가능한 경로를 바로 선택하고 규격과 테스트에 시간을 씁니다.

ROUTE A / AI-ASSISTED

후보를 만들고 사람이 정규화합니다

Sprite Generator 또는 허용된 이미지 도구로 후보를 만들고 Remove Background, Inpaint, Recolor 등을 문제별로 적용합니다. 도구, 모델, prompt와 참조 권리를 모두 기록합니다.

ROUTE B / MANUAL OR OFFLINE

기존 자산을 직접 변형합니다

자신이 만든 또는 이용이 허락된 원본을 복제해 crop, erase, paint, recolor, resize와 frame edit로 같은 규격을 만듭니다. 사용한 수작업 방법과 사람의 판단을 같은 로그에 적습니다.

동등한 평가

AI 경로는 생성량을, 수작업 경로는 작업 시간을 점수로 바꾸지 않습니다. 세 파일의 규격, 두 번 이상의 사람 수정, Unity 통합, 기능 보존, 8개 테스트와 재현 가능한 기록만 같은 기준으로 봅니다.

기록은 이 브라우저에 자동 저장됩니다.

FAIL은 가장 가까운 원인으로 돌아가는 표지입니다

전체를 다시 만들기 전에 이미지, import, animation, UI와 게임 기능 중 어느 층에서 처음 어긋났는지 찾습니다.

원본, alpha→파일 규격→Import, Slice→Clip, UI→Game loop
Sprite 외곽에 흰 선이나 배경 조각이 남습니다

원본을 체커보드 위 100%에서 보고 반투명 halo를 지웁니다. Unity에서는 Alpha Is Transparency와 Filter를 확인합니다. Transform scale로 숨기지 않습니다.

Slice 결과가 4개 또는 3개가 아닙니다

실제 파일 크기, Sprite Mode Multiple, Grid By Cell Size 128×128과 offset, padding 0을 확인하고 Apply합니다. 빈 열이 있다면 source sheet부터 다시 자릅니다.

걷는 동안 캐릭터가 위아래로 튑니다

네 셀의 발 기준선과 투명 여백, Sprite Editor의 Pivot을 같은 값으로 맞춥니다. Clip의 Transform Position key가 우연히 생겼다면 제거합니다.

한 프레임에서 캐릭터가 커지거나 장비가 사라집니다

문제 프레임만 inpaint 또는 직접 페인팅하고 인접 프레임과 실루엣 부피를 비교합니다. 좋은 나머지 세 장을 다시 생성하지 않습니다.

세 상호작용 오브젝트의 역할이 구분되지 않습니다

색만 바꾸기 전에 큰 실루엣을 다르게 만듭니다. 수집물은 작고 둥근 끌림, 위험은 뾰족한 방해, 목표는 열린 통과 형태처럼 기능을 형태에 연결합니다.

UI 패널 모서리와 장식이 늘어납니다

Image라면 Border와 Sliced를 설정하고 stretch되지 않을 모서리 범위를 확인합니다. RawImage라면 원본 비율을 유지하거나 고정 크기로 사용합니다.

아트를 교체한 뒤 충돌, 수집, 버튼이 작동하지 않습니다

SpriteRenderer 또는 Source Image만 바꿨는지 확인합니다. Collider, Tag, Layer, Script, Animator parameter, Prefab override와 Button On Click을 baseline Scene과 비교합니다.

Unity AI 또는 생성 서비스에 접속할 수 없습니다

즉시 Route B로 바꿉니다. 9주차 원본이나 사용 허가된 placeholder를 복제해 erase, paint, recolor, resize와 frame edit로 같은 세 파일을 만들고 수작업 방법을 로그에 남깁니다.
